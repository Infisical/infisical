# Contributing to Infisical

Thanks for taking the time to contribute! 😃 🚀

Please refer to our [Contributing Guide](https://infisical.com/docs/contributing/getting-started/overview) for instructions on how to contribute.

## Contributor License Agreement (CLA)

All contributors must have a signed Contributor License Agreement (CLA) on file before pull requests can be merged:

- **Individual CLA**: Sign digitally via GitHub authentication at [https://cla.infisical.com/sign](https://cla.infisical.com/sign) or through the link provided on your pull request.
- **Corporate CLA (CCLA)**: If contributing on behalf of an employer or organization, review the [Corporate CLA process](.github/CLA.md#corporate-contributor-license-agreement-ccla) or email [contribute@infisical.com](mailto:contribute@infisical.com) / [security@infisical.com](mailto:security@infisical.com) with your signed Schedule A to allowlist authorized GitHub handles.

We also have some 🔥amazing🔥 merch for our contributors. Please reach out to tony@infisical.com for more info 👀
