# Legacy icon set

`icon-data.legacy.ts` is the original Infisical 2.0 line icon set from #8691: 52 hand-drawn 24px glyphs on a 1.7 stroke.

It is kept for reference and for brand-specific marks. It is not used by any component. Lucide (`lucide-react`) is the icon source of truth for v4: `Icon` maps each of these 52 names to its closest Lucide glyph (see `docs/icon.md`).

Nothing in v4 imports this folder, and the registry does not ship it.
