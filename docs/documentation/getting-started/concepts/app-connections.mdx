An App Connection is a stored credential that Infisical uses to authenticate with a third-party service. App Connections are used by Secret Syncs, external migrations, dynamic secret providers, and other integrations that need to reach a system outside of Infisical.

App Connections can be scoped to a single project or to the entire organization. A project-scoped connection is only visible inside the project where it was created. An organization-scoped connection is visible across every project in the organization.

Infisical supports App Connections for cloud providers, secret managers, source control platforms, CI/CD systems, databases, and many other services.
