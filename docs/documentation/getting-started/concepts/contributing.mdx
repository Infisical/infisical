Infisical is [open source](https://github.com/Infisical/infisical), and community contributions are accepted through the main repository. The contributing documentation covers how to set up a local development environment, how to run the platform against a local database, and how to submit a pull request.

Contributions can include bug fixes, new features, documentation updates, and translations. Larger changes are typically discussed in an issue or a draft pull request before implementation begins.
