The internals documentation describes how Infisical is built and how its security-critical components work. This includes the platform's architecture, the components that run in each deployment configuration, the encryption model that protects stored data, and the algorithm used to evaluate permissions.

The internals pages are primarily useful for readers who need to review Infisical for a security audit, integrate with it at a low level, or understand its behavior in edge cases. Users who are only configuring or using the platform typically don't need to read them.
