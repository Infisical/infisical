Some platforms require secrets to be stored in their own secret store in order to be accessible. For example, GitHub Actions reads secrets from repository settings, AWS Lambda reads secrets from AWS Secrets Manager, and Vercel reads secrets from its environment settings. When a secret is stored in both Infisical and one of these platform-specific stores, the value must be updated in both locations whenever it changes, which can cause the values to become inconsistent.

## Solution

[Secret Syncs](/integrations/secret-syncs/overview) forward secrets from an Infisical project to a platform's own secret store. The secret is stored in Infisical, and any change to the secret in Infisical is pushed to the sync destination automatically.

Sync destinations include [GitHub, GitLab, AWS Secrets Manager, GCP Secret Manager, Azure Key Vault, Vercel, and Cloudflare](/integrations/secret-syncs/overview).

## Get started

1. Choose a [sync destination](/integrations/secret-syncs/overview) that matches the platform from which the application reads its secrets.
2. Configure the sync so that Infisical pushes updates to the destination when the source secret changes.
