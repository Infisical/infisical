---

An AI agent that holds an API key or other credential directly is exposed to attacks such as prompt injection, in which a malicious input causes the agent to reveal a credential it has access to. To reduce this risk, the agent can be configured so that it doesn't have access to the credential itself.

## Solution

[Agent Proxy](/documentation/platform/agent-proxy/overview) is a proxy that runs between the agent and the target service. The agent sends its requests to the proxy, and the proxy attaches the required credential to each outbound request before forwarding it to the target service. The credential is stored in Infisical and isn't sent to the agent, so the agent can't expose it.

## Get started

1. Read the [Agent Proxy overview](/documentation/platform/agent-proxy/overview) to learn how the proxy handles requests between an agent and a target service.
2. Follow the [Agent Proxy quickstart](/documentation/platform/agent-proxy/quickstart/credentials) to configure the proxy for a target service.
