Infisical Secret Scanning helps you find credentials, such as API keys, database passwords, and tokens, that were committed to source code.

You can scan code on your own machine (or in CI) using the Infisical CLI, or connect your GitHub, GitLab, and Bitbucket repositories so that Infisical scans them and records each secret it finds.

<Tip>
To learn how Infisical scans your secrets, check out the [Concepts](/documentation/platform/secret-scanning/concepts/secret-scanning) page.
</Tip>
