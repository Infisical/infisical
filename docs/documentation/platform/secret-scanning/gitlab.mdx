To scan your GitLab projects for leaked secrets, create a GitLab [data source](/documentation/platform/secret-scanning/scan-repositories) in Infisical.

## Prerequisites

- A [GitLab Connection](/integrations/app-connections/gitlab) with secret scanning permissions

## Create a GitLab data source in Infisical

<Steps>
  <Step>
    Go to **Secret Scanning** > **Data Sources** and select **Add Data Source**.
    ![Secret Scanning Dashboard](/images/platform/secret-scanning/github/github-data-source-step-1.png)
  </Step>
  <Step>
    Select **GitLab**.
    ![Select GitLab](/images/platform/secret-scanning/gitlab/step-2.png)
  </Step>
  <Step>
    Select the connection to use and the GitLab project or group to scan, then select **Next**.
    ![Data Source Configuration](/images/platform/secret-scanning/gitlab/step-3.png)

    - **GitLab Connection**: The connection that can access the projects you want to scan
    - **Scope**: Whether Infisical scans one GitLab project or the projects in a GitLab group
        - **Project**: Scan the project you select in **Project**
        - **Group**: Scan projects in the group you select in **Group**
    - **Scan Projects**: If **Scope** is **Group**, which of the group's projects Infisical scans
        - **All Projects**: Every project in the group
        - **Select Projects**: Only the projects you select in **Include Projects**
    - **Auto-Scan Enabled**: Whether Infisical scans each new push to the projects
  </Step>
  <Step>
    Enter a name and, optionally, a description for the data source, then select **Next**.
    ![Data Source Details](/images/platform/secret-scanning/gitlab/step-4.png)

    - **Name**: A name that contains only lowercase letters, numbers, and hyphens
    - **Description** (optional): A description of the data source
  </Step>
  <Step>
    Review the data source, then select **Create Data Source**.
    ![Data Source Review](/images/platform/secret-scanning/gitlab/step-5.png)
  </Step>
  <Step>
    The data source appears in **Data Sources**. If auto-scan is enabled, Infisical starts a [historical scan](/documentation/platform/secret-scanning/scan-repositories#scans) of every project.
    ![Data Source Created](/images/platform/secret-scanning/gitlab/step-6.png)
  </Step>
  <Step>
    To see the data source's projects and scan history, select the data source.
    ![Data Source Page](/images/platform/secret-scanning/gitlab/step-7.png)
  </Step>
  <Step>
    To review the secrets the scans found, go to **Findings**. To learn what each finding contains and how to change its status, see [Findings](/documentation/platform/secret-scanning/findings).
    ![Findings Page](/images/platform/secret-scanning/gitlab/step-8.png)
  </Step>
</Steps>
