To scan your GitLab projects for leaked secrets, create a GitLab [data source](/documentation/platform/secret-scanning/scan-repositories) in Infisical.

## Prerequisites

- A [GitLab Connection](/integrations/app-connections/gitlab) with secret scanning permissions

## Create a GitLab data source in Infisical

<Steps>
  <Step>
    Go to **Secret Scanning** > **Data Sources** and select **Add Data Source**.
    ![Secret Scanning Dashboard](/images/platform/secret-scanning/github/github-data-source-step-1.png)
  </Step>
  <Step>
    Select **GitLab**.
    ![Select GitLab](/images/platform/secret-scanning/gitlab/step-2.png)
  </Step>
  <Step>
    Select the connection to use and, optionally, a GitLab group, then select **Continue**.
    ![Data Source Configuration](/images/platform/secret-scanning/gitlab/step-3.png)

    - **GitLab Connection**: The connection that can access the projects you want to scan
    - **Group** (optional): The GitLab group whose projects the data source covers. If you leave it empty, the data source covers every project the connection can read, including your own.

    You can't change the connection or the group after you create the data source. Each connection can be used by only one data source, so to scan two GitLab groups, create a separate GitLab connection for each.
  </Step>
  <Step>
    Choose when Infisical scans the data source's projects, then select **Continue**.

    - **Trigger Historical Scan**: Whether Infisical scans the full history of each project you add to the data source
    - **Scan New Commits**: Whether Infisical scans each new push to the data source's projects
    - **Discover New Projects**: Whether Infisical adds every project in the group when you create the data source, and adds projects created in the group later. This option requires a group, because GitLab only reports new projects through group webhooks.
  </Step>
  <Step>
    Enter a name and, optionally, a description for the data source, then select **Continue**.
    ![Data Source Details](/images/platform/secret-scanning/gitlab/step-4.png)

    - **Name**: A name that contains only lowercase letters, numbers, and hyphens
    - **Description** (optional): A description of the data source
  </Step>
  <Step>
    Review the data source, then select **Create Data Source**.
    ![Data Source Review](/images/platform/secret-scanning/gitlab/step-5.png)
  </Step>
  <Step>
    The data source appears in **Data Sources**. If **Discover New Projects** is on, Infisical adds every project in the group, and starts a [historical scan](/documentation/platform/secret-scanning/scan-repositories#scans) of each one if **Trigger Historical Scan** is on. Otherwise, [add the projects](/documentation/platform/secret-scanning/scan-repositories#resources) you want to scan. If you didn't select a group, add each project individually.
    ![Data Source Created](/images/platform/secret-scanning/gitlab/step-6.png)
  </Step>
  <Step>
    To see the data source's projects and scan history, select the data source.
    ![Data Source Page](/images/platform/secret-scanning/gitlab/step-7.png)
  </Step>
  <Step>
    To review the secrets the scans found, go to **Findings**. To learn what each finding contains and how to change its status, see [Findings](/documentation/platform/secret-scanning/findings).
    ![Findings Page](/images/platform/secret-scanning/gitlab/step-8.png)
  </Step>
</Steps>
