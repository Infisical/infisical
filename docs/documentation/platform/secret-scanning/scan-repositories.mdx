Infisical can scan your GitHub, GitLab, and Bitbucket repositories for leaked secrets. It scans each repository's full commit history, and can also scan each new push as it arrives.

Infisical records every secret it finds as a [finding](/documentation/platform/secret-scanning/findings) that you can track until it's handled, and the [scanning configuration](/documentation/platform/secret-scanning/configuration) sets the rules it scans with.

<Info>
  Scanning repositories is available under Infisical's [Enterprise](https://infisical.com/pricing) plan. If you're self-hosting Infisical, contact sales@infisical.com to purchase an enterprise license.
  
  You don't need a license to [scan locally using the CLI](/documentation/platform/secret-scanning/scan-locally).
</Info>

## Data sources

To scan repositories, connect them to Infisical with a data source. A data source covers the repositories in a GitHub organization, the GitLab projects a connection can read or a GitLab group, or a Bitbucket workspace. It reaches them through an [app connection](/integrations/app-connections/overview), and each app connection can back only one data source. To create one, follow the guide for your provider:

### Resources

A resource is one repository that a data source scans, such as a GitHub repository or a GitLab project. A data source scans only the resources added to it.

If **Discover New Repositories** (or **Discover New Projects** for GitLab) is on, Infisical adds every resource the connection can access when you create the data source, and adds resources created in the provider later.

To add resources yourself, select the data source, open its **Repositories** or **Projects** tab, and select **Add Repository** or **Add Project**. Then choose one of these options:

- **Add Repository** or **Add Project**: Add one resource
- **Add All Repositories** or **Add All Projects**: Add every resource the connection can access. This option isn't available for a GitLab data source without a group.

To stop scanning a resource, select the options menu on the resource's row, then select **Remove Repository** or **Remove Project**. Infisical permanently deletes the resource's scans and findings.

To see a data source's resources and its **Scan History**, select the data source.

## Scans

Infisical runs two types of scan:

- **Historical scan**: Scans every commit in a repository, from the first to the latest
- **Realtime scan**: Scans only the commits in a new push

Two options on each data source control when Infisical scans automatically:

- **Trigger Historical Scan**: Infisical runs a historical scan of each resource when it's added to the data source
- **Scan New Commits**: Infisical runs a realtime scan of every new push to the data source's resources

To turn these options on or off, select the data source, open its **Settings** tab, and use the toggles in **Scanning**. You can also change them by selecting **Edit Data Source** in the options menu on the data source's row.

### Run a historical scan

You can run a historical scan at any time:

- **Every resource in a data source**: Select the data source, select **Options**, then select **Scan All Repositories** or **Scan All Projects**
- **One resource**: Select the data source, then select the options menu on the resource's row and select **Trigger Scan**

### Scan history

The **Scan History** on a data source's page shows each scan's type, its status, and whether it found any secrets.
