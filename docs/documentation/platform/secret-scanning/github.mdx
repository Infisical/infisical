To scan your GitHub repositories for leaked secrets, create a GitHub [data source](/documentation/platform/secret-scanning/scan-repositories) in Infisical.

## Prerequisites

- A [GitHub Radar Connection](/integrations/app-connections/github-radar)

## Create a GitHub data source in Infisical

<Steps>
  <Step>
    Go to **Secret Scanning** > **Data Sources** and select **Add Data Source**.
    ![Secret Scanning Dashboard](/images/platform/secret-scanning/github/github-data-source-step-1.png)
  </Step>
  <Step>
    Select **GitHub**.
    ![Select GitHub Option](/images/platform/secret-scanning/github/github-data-source-step-2.png)
  </Step>
  <Step>
    Select the connection to use and the repositories to scan, then select **Next**.
    ![Data Source Configuration](/images/platform/secret-scanning/github/github-data-source-step-3.png)

    - **GitHub Radar Connection**: The connection that can access the repositories you want to scan
    - **Scan Repositories**: Which repositories Infisical scans
        - **All Repositories**: Every repository the connection can access
        - **Select Repositories**: Only the repositories you select in **Include Repositories**
    - **Auto-Scan Enabled**: Whether Infisical scans each new push to the repositories
  </Step>
  <Step>
    Enter a name and, optionally, a description for the data source, then select **Next**.
    ![Data Source Details](/images/platform/secret-scanning/github/github-data-source-step-4.png)

    - **Name**: A name that contains only lowercase letters, numbers, and hyphens
    - **Description** (optional): A description of the data source
  </Step>
  <Step>
    Review the data source, then select **Create Data Source**.
    ![Data Source Review](/images/platform/secret-scanning/github/github-data-source-step-5.png)
  </Step>
  <Step>
    The data source appears in **Data Sources**. If auto-scan is enabled, Infisical starts a [historical scan](/documentation/platform/secret-scanning/scan-repositories#scans) of every repository.
    ![Data Source Created](/images/platform/secret-scanning/github/github-data-source-step-6.png)
  </Step>
  <Step>
    To see the data source's repositories and scan history, select the data source.
    ![Data Source Page](/images/platform/secret-scanning/github/github-data-source-step-7.png)
  </Step>
  <Step>
    To review the secrets the scans found, go to **Findings**. To learn what each finding contains and how to change its status, see [Findings](/documentation/platform/secret-scanning/findings).
    ![Findings Page](/images/platform/secret-scanning/github/github-data-source-step-8.png)
  </Step>
</Steps>
