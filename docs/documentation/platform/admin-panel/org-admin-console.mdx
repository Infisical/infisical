<Note>

  organization.
</Note>

## Viewing every project in the organization

Project membership normally decides what you can see: a project you haven't joined doesn't appear in your project list. Organization admins are the exception. They can list every project of a given type and join any of them.

Open a product from the organization overview, then select the **All Projects** tab. It lists every project of that type in the organization, including the ones you aren't a member of, and you can narrow the list by name with the search bar.

![Projects Section](/images/platform/admin-panels/org-admin-console-projects.png)

## Accessing a project you aren't a member of

Projects you have already joined are marked **Joined**. Any other project shows a **Join as Admin** button. Selecting it adds you to that project as an admin and grants you full permissions there.

![Join as Admin on a project you haven't joined](/images/platform/admin-panels/org-admin-console-access.png)

<Note>
  Joining a project this way is recorded in the
  [audit log](/documentation/platform/audit-logs), so the project's own admins
  can see that you joined.
</Note>
