Honey tokens are decoy credentials that act as tripwires. When an attacker gains access to your secrets and attempts to use a honey token, Infisical detects the activity and immediately alerts you and your team.

Each honey token is planted alongside your real secrets so it appears genuine. Any attempt to use these credentials triggers an alert, which notifies the people and channels you [choose for that honey token](/documentation/platform/honey-tokens/usage#get-alerted-when-a-honey-token-is-triggered).

At this time, we only support [AWS IAM](/documentation/platform/honey-tokens/usage) credentials as honey tokens, but we're planning to support more providers in the near future.

## Get started

On Infisical Cloud, you can create honey tokens right away, with no setup. If you self-host Infisical, an organization admin first connects your own AWS account.

## Permissions

These project permissions control who can create and manage honey tokens. Connecting [your own AWS account](/documentation/platform/honey-tokens/own-aws-account) needs a separate organization permission.

| Action | Description | Admin | Member | Viewer |
| --- | --- | --- | --- | --- |
| **Read** | View honey tokens, their status, and trigger events | Yes | Yes | Yes |
| **Read Credentials** | View the actual decoy credential values (e.g., AWS access keys) | Yes | No | No |
| **Create** | Create new honey tokens and plant decoy secrets | Yes | No | No |
| **Edit** | Update honey token name, description, or secret mappings | Yes | No | No |
| **Reset** | Reset a triggered honey token back to active status | Yes | No | No |
| **Revoke** | Permanently deactivate and remove a honey token | Yes | No | No |

To give a role other than Admin more of these actions, create a [custom role](/documentation/platform/access-controls/role-based-access-controls) with the actions it needs.

Infisical stores the decoy credentials as regular secrets in your project. To see them in the secrets dashboard, a user also needs permission to read secrets in the honey token's environment and path.
