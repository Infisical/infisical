A Windows account lets people open a remote desktop (RDP) session on one Windows server without seeing the account's password. They connect with an RDP client in the browser or with their own RDP client through the Infisical CLI, and Infisical records each [session](/documentation/platform/pam/sessions/overview).

To sign in to several servers with one Active Directory account, use a [Windows AD account](/documentation/platform/pam/accounts/windows-ad) instead.

<Info>
  Windows accounts are available under Infisical's [Enterprise](https://infisical.com/pricing) plan.
</Info>

## Prerequisites

- The Admin [role](/documentation/platform/pam/concepts/access-control) on the [folder](/documentation/platform/pam/folders/overview) you'll add the account to
- A [Gateway](/documentation/platform/gateways/overview) that can reach the server on its RDP port
- A Windows [template](/documentation/platform/pam/templates/overview) that stores recordings in [your own S3 bucket](/documentation/platform/pam/sessions/external-storage) (the default Windows template stores them in Infisical's database, so a Product Admin must change it or create another template)

## Create an account

<Steps>
  <Step>
    Go to **Privileged Access Management** > **Accounts** and select **Add Account**.
  </Step>
  <Step>
    Select the **Folder** to add the account to and a Windows **Account Template**, then select **Next**.
  </Step>
  <Step>
    Enter a **Name** for the account and the server's connection details:

    | Field | Description |
    |-------|-------------|
    | **Host** | The server's hostname or IP address |
    | **RDP Port** | The server's RDP port (defaults to `3389`) |
    | **WinRM Port** | The server's WinRM port (defaults to `5985`) |
    | **Use WinRM HTTPS** | Whether to connect to WinRM over HTTPS |
    | **Gateway** | The Gateway that connects to the server (only shown if the template doesn't set one) |

    Infisical uses WinRM for [credential rotation](/documentation/platform/pam/credential-rotation/windows), [credential health](/documentation/platform/pam/credential-health/overview) checks, and [dependency](/documentation/platform/pam/credential-rotation/windows#dependencies) detection, not for RDP sessions.
  </Step>
  <Step>
    Enter the **Username** and **Password** of the local Windows account.
    
    <Note>
    Enter the username on its own, such as `svc-backup`, without a `.\` or computer name in front of it.
    </Note>
  </Step>
  <Step>
    Select **Create**.
  </Step>
</Steps>

## Connect

People can open a remote desktop in the browser or connect through the CLI. To learn how to launch a session, see [Connect to an account](/documentation/platform/pam/accounts/connect).

The CLI starts a local proxy and prints its port:

```bash
infisical pam access <folder>/<account>
```

Point your RDP client at `localhost` on that port, for example:

```bash
xfreerdp /v:localhost:<port>
```

Press `Ctrl+C` to end the session.
