A MariaDB [account](/documentation/platform/pam/accounts/overview) stores the credentials for one MariaDB database user. Members connect to the database in the browser or through the Infisical CLI, and Infisical records every query they run.

## Prerequisites

- The Admin [role](/documentation/platform/pam/concepts/access-control) on the [folder](/documentation/platform/pam/folders/overview) you'll add the account to
- A [gateway](/documentation/platform/gateways/overview) that can reach the database
- A MariaDB [account template](/documentation/platform/pam/templates/overview)
- A [MariaDB user](https://mariadb.com/docs/server/reference/sql-statements/account-management-sql-statements/create-user) for Infisical to connect as

## Create the account

<Steps>
  <Step>
    Go to **Privileged Access Management** > **Accounts** and select **Add Account**.
  </Step>
  <Step>
    Select the **Folder** and a MariaDB **Account Template**, then select **Next**.
  </Step>
  <Step>
    Enter a **Name** and the connection details:

    | Field | Description |
    | --- | --- |
    | **Host** | The database's hostname or IP address |
    | **Port** | The database's port (defaults to `3306`) |
    | **Database** | The database that sessions connect to |
    | **SSL Enabled** | Whether to connect over TLS |
    | **Reject Unauthorized** | Whether to reject a server certificate that can't be verified (shown when **SSL Enabled** is on) |
    | **SSL Certificate** | The CA certificate that signed the server's certificate (shown when **SSL Enabled** is on) |
  </Step>
  <Step>
    Enter the **Username** and **Password** of the MariaDB user, then select **Create**.
  </Step>
</Steps>

## Connect

To open a session, follow [Connect to an account](/documentation/platform/pam/accounts/connect).

<Tabs>
  <Tab title="Browser">
    The browser session has a table browser, where you can view, filter, edit, and export rows, and a SQL editor for running queries.
  </Tab>
  <Tab title="CLI">
    <Steps>
      <Step>
        Start the local proxy:

        ```bash
        infisical pam access backend-team/orders-db
        ```

        The proxy keeps running in that terminal and prints its port.
      </Step>
      <Step>
        In a second terminal, connect your MariaDB or MySQL client to that port:

        ```bash
        mariadb -h 127.0.0.1 -P <port> orders
        ```

        The proxy signs in for you, so the client doesn't need a password.
      </Step>
    </Steps>
  </Tab>
</Tabs>

## Rotate the password

MariaDB accounts rotate the same way as MySQL accounts. Follow [MySQL credential rotation](/documentation/platform/pam/credential-rotation/mysql) for the privileges and SQL grants the rotation account needs, but add both users to Infisical PAM as MariaDB accounts. A MariaDB account can only use another MariaDB account as its rotation account, so a MySQL account won't appear in the list.
