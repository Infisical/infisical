An Oracle [account](/documentation/platform/pam/accounts/overview) stores the credentials for one Oracle database user. Members connect to the database through the Infisical CLI, and Infisical records every statement they run.

## Prerequisites

- The Admin [role](/documentation/platform/pam/concepts/access-control) on the [folder](/documentation/platform/pam/folders/overview) you'll add the account to
- A [gateway](/documentation/platform/gateways/overview) that can reach the database
- An Oracle [account template](/documentation/platform/pam/templates/overview)
- An Oracle password of 30 characters or fewer, because the gateway can't sign in with a longer one

## Create the account

<Steps>
  <Step>
    Go to **Privileged Access Management** > **Accounts** and select **Add Account**.
  </Step>
  <Step>
    Select the **Folder** and an Oracle **Account Template**, then select **Next**.
  </Step>
  <Step>
    Enter a **Name** and the connection details:

    | Field | Description |
    | --- | --- |
    | **Host** | The database's hostname or IP address |
    | **Port** | The listener's port (defaults to `1521`; the TCPS listener usually uses `2484`) |
    | **Service Name** | The Oracle service name, such as `ORCL` or `FREEPDB1` |
    | **SSL Enabled** | Whether to connect to the TCPS listener |
    | **Reject Unauthorized** | Whether to reject a server certificate that can't be verified (shown when **SSL Enabled** is on) |
    | **SSL Certificate** | The CA certificate that signed the server's certificate (shown when **SSL Enabled** is on) |
  </Step>
  <Step>
    Enter the credentials:

    | Field | Description |
    | --- | --- |
    | **Username** | The Oracle user, exactly as Oracle stores it (Oracle stores unquoted names in uppercase) |
    | **Password** | The user's password |
  </Step>
  <Step>
    Select **Create**.
  </Step>
</Steps>

When you select **Create**, Infisical only checks that it can reach the host and port. The first [credential health check](/documentation/platform/pam/credential-health/overview) checks the username and password, and reports **Out of Sync** if Oracle rejects them.

## Connect

To open a session, follow [Connect to an account](/documentation/platform/pam/accounts/connect). Oracle accounts don't support the browser, so use the CLI.

Start the local proxy. The CLI prints the port, the username, and the service name to connect with:

```bash
infisical pam access finance/billing-db
```

The proxy keeps running in that terminal. In a second terminal, connect your Oracle client, such as `sqlplus` or SQL Developer, to the port:

```bash
sqlplus <username>/password@127.0.0.1:<port>/<service-name>
```
