title: "Accounts"
sidebarTitle: "Overview"
description: "Store the credentials for a database or server that people and agents connect to through Infisical PAM."
---

An account is one set of credentials for a database, server, cluster, or cloud provider, along with the details Infisical needs to reach it. People and [AI agents](/documentation/platform/pam/ai-agents/overview) connect to an account through Infisical. A [gateway](/documentation/platform/gateways/overview) supplies the credential, so whoever connects never sees it.

Each account belongs to one [folder](/documentation/platform/pam/folders/overview), which sets who can use the account. Each account also uses one [account template](/documentation/platform/pam/templates/overview), which sets the account type and the rules for its sessions.
