A Redis [account](/documentation/platform/pam/accounts/overview) stores the credentials for one Redis user. Members connect to the database in the browser or through the Infisical CLI, and Infisical records every command they run.

## Prerequisites

- The Admin [role](/documentation/platform/pam/concepts/access-control) on the [folder](/documentation/platform/pam/folders/overview) you'll add the account to
- A [gateway](/documentation/platform/gateways/overview) that can reach the database
- A Redis [account template](/documentation/platform/pam/templates/overview)

## Create the account

<Steps>
  <Step>
    Go to **Privileged Access Management** > **Accounts** and select **Add Account**.
  </Step>
  <Step>
    Select the **Folder** and a Redis **Account Template**, then select **Next**.
  </Step>
  <Step>
    Enter a **Name** and the connection details:

    | Field | Description |
    | --- | --- |
    | **Host** | The database's hostname or IP address |
    | **Port** | The database's port (defaults to `6379`) |
    | **SSL Enabled** | Whether to connect over TLS |
    | **Reject Unauthorized** | Whether to reject a server certificate that can't be verified (shown when **SSL Enabled** is on) |
    | **SSL Certificate** | The CA certificate that signed the server's certificate (shown when **SSL Enabled** is on) |
  </Step>
  <Step>
    Enter the credentials:

    | Field | Description |
    | --- | --- |
    | **Username** | The Redis ACL user (defaults to `default`, which also works with a `requirepass` password on Redis 6 and later) |
    | **Password** | The user's password (leave it empty if the server doesn't require authentication) |
  </Step>
  <Step>
    Select **Create**.
  </Step>
</Steps>

## Connect

To open a session, follow [Connect to an account](/documentation/platform/pam/accounts/connect).

<Tabs>
  <Tab title="Browser">
    The browser session is a console where you type Redis commands, the same way you would in `redis-cli`. To end the session, type `quit` or `exit`.

    The console shortens very long replies, and doesn't support commands that stream results, such as `SUBSCRIBE` and `MONITOR`. To run those commands, use the CLI.
  </Tab>
  <Tab title="CLI">
    Start the local proxy:

    ```bash
    infisical pam access backend-team/cache-primary
    ```

    The proxy keeps running in that terminal and prints its port. In a second terminal, connect your Redis client to that port:

    ```bash
    redis-cli -h 127.0.0.1 -p <port>
    ```

    The proxy signs in for you, so the client doesn't need a password.
  </Tab>
</Tabs>
