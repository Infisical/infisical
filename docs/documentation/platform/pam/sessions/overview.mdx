Each time a person or an [AI agent](/documentation/platform/pam/ai-agents/overview) connects to an [account](/documentation/platform/pam/accounts/overview), Infisical creates a session. The session records who connected, when, for how long, and what they did. To learn how a session starts and ends, see [Concepts](/documentation/platform/pam/concepts/overview).

## Who can see sessions

To see an account's sessions, you need the **Admin** or **Auditor** [role](/documentation/platform/pam/concepts/access-control) on the account or on its [folder](/documentation/platform/pam/folders/overview). The **Connector** and **Operator** roles let you launch sessions, but they don't let you see sessions on the **Sessions** page.

## View sessions

Go to **Privileged Access Management** > **Sessions**. The list shows each session's user, account, folder, start time, duration, and status.

To find a session:

- Search by account name, folder name, or the user's name or email
- Filter by status to show only **Active** or **Ended** sessions

If a [machine identity](/documentation/platform/identities/machine-identities) opened the session, the list shows **Machine Identity** in place of an email address.

### Session details

Select a session to open its details:

- The user's email and IP address, the folder, and the session's start time, end time, and duration
- The reason the user gave, if the account's [template](/documentation/platform/pam/templates/overview) requires one
- The [session recording](/documentation/platform/pam/sessions/session-recording) of what happened during the session

While a session is active, its recording updates as the user works, so you can follow what they do.

## Terminate a session

To end a session right away, such as during a security incident or when an agent does more than you expected, terminate it. You need the **Admin** role on the account or its folder.

<Steps>
  <Step>
    Go to **Privileged Access Management** > **Sessions**.
  </Step>
  <Step>
    On the row of the active session, select **Terminate**.
  </Step>
  <Step>
    Type `terminate` to confirm, then select **Terminate**.
  </Step>
</Steps>

Infisical disconnects the user or agent right away.

<Warning>
  Terminating a session doesn't stop the user from launching a new one. To stop someone from connecting again, remove their [membership](/documentation/platform/pam/concepts/access-control) on the account or folder.
</Warning>
