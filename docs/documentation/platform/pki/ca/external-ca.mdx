Integrate with External Certificate Authorities (CAs) to use existing PKI infrastructure or connect to public CAs for certificate issuance.

<Info>
  This page is for product admins setting up PKI infrastructure. Teams issuing certificates should see [Applications](/documentation/platform/pki/applications/overview).
</Info>

## Public CAs

Public CAs issue certificates that browsers trust, for public-facing services:

<CardGroup cols={2}>
  <Card title="ACME-compatible CA" icon="bot" href="/documentation/platform/pki/ca/acme-ca">
    Connect to any CA that supports ACME, such as ZeroSSL or Buypass.
  </Card>
  <Card title="Let's Encrypt" icon="lock" href="/documentation/platform/pki/ca/lets-encrypt">
    Free, automated certificates for public domains.
  </Card>
  <Card title="DigiCert (ACME)" icon="shield-check" href="/documentation/platform/pki/ca/digicert">
    DigiCert certificates through ACME with External Account Binding.
  </Card>
  <Card title="DigiCert (CertCentral API)" icon="shield-half" href="/documentation/platform/pki/ca/digicert-direct">
    DigiCert TLS and code signing certificates through the CertCentral Services API.
  </Card>
  <Card title="GoDaddy" icon="globe" href="/documentation/platform/pki/ca/godaddy">
    Domain Validated certificates through the GoDaddy Certificates API.
  </Card>
  <Card title="Sectigo" icon="award" href="/documentation/platform/pki/ca/sectigo">
    Sectigo certificates through ACME with External Account Binding.
  </Card>
  <Card title="AWS ACM public CA" icon="aws" iconType="brands" href="/documentation/platform/pki/ca/aws-acm-public-ca">
    Publicly trusted certificates from AWS Certificate Manager.
  </Card>
</CardGroup>

## Private CAs

Private CAs issue certificates for internal services, from PKI you already run in the cloud or on premises:

<CardGroup cols={2}>
  <Card title="Microsoft ADCS" icon="microsoft" iconType="brands" href="/documentation/platform/pki/ca/adcs">
    Microsoft AD CS over MS-WCCE through an Infisical Gateway.
  </Card>
  <Card title="Azure ADCS (web enrollment)" icon="microsoft" iconType="brands" href="/documentation/platform/pki/ca/azure-adcs">
    Microsoft AD CS over HTTPS web enrollment.
  </Card>
  <Card title="AWS private CA" icon="aws" iconType="brands" href="/documentation/platform/pki/ca/aws-pca">
    Private certificates from AWS Private Certificate Authority.
  </Card>
  <Card title="Venafi TLS Protect Cloud" icon="cloud" href="/documentation/platform/pki/ca/venafi">
    Venafi's cloud-based certificate management platform.
  </Card>
  <Card title="Venafi TPP" icon="server" href="/documentation/platform/pki/ca/venafi-tpp">
    Venafi Trust Protection Platform, on premises.
  </Card>
</CardGroup>
