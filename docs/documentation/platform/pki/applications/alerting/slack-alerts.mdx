A Slack channel on a certificate [alert](/documentation/platform/pki/applications/alerting/overview) posts to Slack whenever the alert fires. Infisical can post to Slack in two ways:

| Method | How it posts | Best for |
|--------|--------------|----------|
| **Slack integration** | Through your organization's [Slack integration](/documentation/platform/workflow-integrations/slack-integration), to any channels you pick | Sending different alerts to different teams' channels without managing a webhook per channel |
| **Incoming webhook** | Through a Slack [Incoming Webhook](https://api.slack.com/messaging/webhooks), to the one channel the webhook was created for | Organizations that don't want to install the Infisical Slack app |

<Info>
  Slack channels are available under Infisical's [Enterprise](https://infisical.com/pricing) plan. If you're self-hosting Infisical, contact sales@infisical.com to purchase an enterprise license.
</Info>

## Prerequisites

- The Certificate Management **Admin** role to create an organization-wide alert, or the **Admin** [application role](/documentation/platform/pki/applications/overview#application-roles) to create an application alert
- To post through the Slack integration, a [Slack integration](/documentation/platform/workflow-integrations/slack-integration) in your organization, and permission to read organization settings
- To post through an incoming webhook, a Slack workspace where you can create apps

## Post through the Slack integration

<Note>
  To post to a private Slack channel, add the Infisical app to the channel in Slack first. Until you add the app, the channel doesn't appear in the list of channels.
</Note>

<Tabs>
  <Tab title="Infisical UI">
    <StartAlert />

    On the **Channels** step, add the Slack channel:

    <Steps>
      <Step>
        Select **Add Channel** > **Slack**, and keep **Slack app** selected on the channel.
      </Step>
      <Step>
        Select a **Slack integration**, then select one or more **Slack channels**, up to 20.
      </Step>
      <Step>
        Optionally, select **Send test** to send a test message to the selected Slack channels.
      </Step>
      <Step>
        Select **Continue**, check the **Review** step, and select **Create Alert**.
      </Step>
    </Steps>
  </Tab>
  <Tab title="API">
    <Steps>
      <Step>
        List your organization's workflow integrations, and copy the `id` of the Slack integration to post through:

        ```bash
        curl --url https://app.infisical.com/api/v1/workflow-integrations \
          --header 'Authorization: Bearer <access-token>'
        ```
      </Step>
      <Step>
        List that integration's Slack channels, and copy the `id` and `name` of each channel to post to:

        ```bash
        curl --url https://app.infisical.com/api/v1/workflow-integrations/slack/<slack-integration-id>/channels \
          --header 'Authorization: Bearer <access-token>'
        ```
      </Step>
      <Step>
        Call the [Create alert](/api-reference/endpoints/alerts/create) endpoint with a `slack-app` channel. In the channel's `config`, set `workflowIntegrationId` to the integration ID and `channels` to the channels from the previous step.
      </Step>
    </Steps>

    <AlertApiFields />

    ```bash
    curl --request POST \
      --url https://app.infisical.com/api/v1/alerts \
      --header 'Authorization: Bearer <access-token>' \
      --header 'Content-Type: application/json' \
      --data '{
        "name": "payments-api-expiring",
        "resourceType": "cert-manager.application",
        "resourceId": "<application-id>",
        "eventType": "cert-manager.application.certificate.expiry",
        "condition": { "alertBefore": "30d" },
        "channels": [
          {
            "name": "payments-slack",
            "channelType": "slack-app",
            "config": {
              "workflowIntegrationId": "<slack-integration-id>",
              "channels": [
                { "id": "<slack-channel-id>", "name": "payments-team" },
                { "id": "<slack-channel-id>", "name": "security" }
              ]
            }
          }
        ]
      }'
    ```
  </Tab>
</Tabs>

<Check>
  Your alert is set up. Infisical posts to each selected Slack channel whenever the alert fires.
</Check>

### If a Slack integration is deleted

If someone deletes the Slack integration that an alert posts through, the alert's Slack channel stops sending messages, and the alert's **Last Run** column shows **Failed**. To fix the alert, edit the alert and select another Slack integration on its **Channels** step.

When you delete a Slack integration in Infisical, the confirmation dialog shows how many alerts post through the integration.

## Post through an incoming webhook

### Step 1: Create a Slack incoming webhook

<Steps>
  <Step>
    Go to the [Slack API Apps page](https://api.slack.com/apps), select **Create New App**, then select **From scratch**.
  </Step>
  <Step>
    Name the app, for example `Infisical PKI Alerts`, pick your workspace, and select **Create App**.
  </Step>
  <Step>
    In the app settings, go to **Incoming Webhooks** and turn on **Activate Incoming Webhooks**.
  </Step>
  <Step>
    Select **Add New Webhook to Workspace**, pick the Slack channel for alerts, and select **Allow**.
  </Step>
  <Step>
    Copy the **Webhook URL**.

    <Note>
      Anyone with the webhook URL can post to your Slack channel, so store it like a secret.
    </Note>
  </Step>
</Steps>

### Step 2: Create the alert

<Tabs>
  <Tab title="Infisical UI">
    <StartAlert />

    On the **Channels** step, add the Slack channel:

    <Steps>
      <Step>
        Select **Add Channel** > **Slack**, select **Webhook URL** on the channel, and paste the URL from [step 1](#step-1-create-a-slack-incoming-webhook) into **Webhook URL**. The URL must start with `https://hooks.slack.com`.
      </Step>
      <Step>
        Optionally, select **Send test** to send a test message to the Slack channel.
      </Step>
      <Step>
        Select **Continue**, check the **Review** step, and select **Create Alert**.
      </Step>
    </Steps>
  </Tab>
  <Tab title="API">
    Send a request to the create alert endpoint with an [access token](/api-reference/overview/authentication) and a `slack` channel, and set `webhookUrl` in the channel's `config` to the URL from [step 1](#step-1-create-a-slack-incoming-webhook).

    <AlertApiFields />

    <CodeGroup>
    ```bash Organization-wide
    curl --request POST \
      --url https://app.infisical.com/api/v1/alerts \
      --header 'Authorization: Bearer <access-token>' \
      --header 'Content-Type: application/json' \
      --data '{
        "name": "certificate-revocations",
        "resourceType": "cert-manager",
        "eventType": "cert-manager.certificate.revocation",
        "channels": [
          {
            "name": "pki-alerts",
            "channelType": "slack",
            "config": { "webhookUrl": "<slack-webhook-url>" }
          }
        ]
      }'
    ```

    ```bash Application
    curl --request POST \
      --url https://app.infisical.com/api/v1/alerts \
      --header 'Authorization: Bearer <access-token>' \
      --header 'Content-Type: application/json' \
      --data '{
        "name": "payments-api-expiring",
        "resourceType": "cert-manager.application",
        "resourceId": "<application-id>",
        "eventType": "cert-manager.application.certificate.expiry",
        "condition": { "alertBefore": "30d" },
        "channels": [
          {
            "name": "payments-alerts",
            "channelType": "slack",
            "config": { "webhookUrl": "<slack-webhook-url>" }
          }
        ]
      }'
    ```
    </CodeGroup>
  </Tab>
</Tabs>

<Check>
  Your alert is set up. Infisical posts to the Slack channel whenever the alert fires.
</Check>

## Message format

Each Slack message includes the alert's summary, up to two certificates, and a **View in Infisical** button. For an application alert, the button opens the application. For an organization-wide alert, it opens the **Inventory** page, or the **Signers** page for a signer certificate expiration alert. In every alert except signer certificate expiration, select a certificate's name to open that certificate in Infisical.

The message color shows the alert's severity:

| Color | Severity | When |
|-------|----------|------|
| Red | Critical or error | A certificate expires within 14 days |
| Amber | Warning | A certificate expires within 15 to 30 days, or a certificate was revoked |
| Blue | Info | A certificate expires in more than 30 days, or a certificate was issued or renewed |
