A Slack channel on a certificate [alert](/documentation/platform/pki/applications/alerting/overview) posts to a Slack channel through an [Incoming Webhook](https://api.slack.com/messaging/webhooks) whenever the alert fires.

<Info>
  Slack channels are available under Infisical's [Enterprise](https://infisical.com/pricing) plan. If you're self-hosting Infisical, contact sales@infisical.com to purchase an enterprise license.
</Info>

## Prerequisites

- The Certificate Management **Admin** role to create a Certificate Management alert, or the **Admin** [application role](/documentation/platform/pki/applications/overview#application-roles) to create an application alert
- A Slack workspace where you can create apps

## Step 1: Create a Slack incoming webhook

<Steps>
  <Step>
    Go to the [Slack API Apps page](https://api.slack.com/apps), select **Create New App**, then select **From scratch**.
  </Step>
  <Step>
    Name the app, for example `Infisical PKI Alerts`, pick your workspace, and select **Create App**.
  </Step>
  <Step>
    In the app settings, go to **Incoming Webhooks** and turn on **Activate Incoming Webhooks**.
  </Step>
  <Step>
    Select **Add New Webhook to Workspace**, pick the Slack channel for alerts, and select **Allow**.
  </Step>
  <Step>
    Copy the **Webhook URL**.

    <Note>
      Anyone with the webhook URL can post to your Slack channel, so store it like a secret.
    </Note>
  </Step>
</Steps>

      <Tab title="API">
        Send a request to the create alert endpoint with a `slack` channel, and set `webhookUrl` in the channel's `config` to the URL from [step 1](#step-1-create-a-slack-incoming-webhook). To choose the alert's event and settings, see [Create an alert through the API](/documentation/platform/pki/applications/alerting/overview#create-an-alert-through-the-api).

        ```bash Request
        curl --request POST \
          --url https://app.infisical.com/api/v1/alerts \
          --header 'Authorization: Bearer <access-token>' \
          --header 'Content-Type: application/json' \
          --data '{
            "name": "certificate-revocations",
            "resourceType": "cert-manager",
            "eventType": "cert-manager.certificate.revocation",
            "channels": [
              {
                "name": "pki-alerts",
                "channelType": "slack",
                "config": { "webhookUrl": "<slack-webhook-url>" }
              }
            ]
          }'
        ```

## Message format

Each Slack message includes the alert's summary, up to two certificates, and a **View in Infisical** button. For an application alert, the button opens the application. For a Certificate Management alert, it opens the **Inventory** page, or the **Signers** page for a signer certificate expiration alert. The message color shows the alert's severity:

| Color | Severity | When |
|-------|----------|------|
| Red | Critical or error | A certificate expires within 14 days |
| Amber | Warning | A certificate expires within 15 to 30 days, or a certificate was revoked |
| Blue | Info | A certificate expires in more than 30 days, or a certificate was issued or renewed |
