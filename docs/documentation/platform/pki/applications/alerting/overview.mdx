Certificate alerting tells your team about certificate lifecycle events in an [Application](/documentation/platform/pki/applications/overview). You create alerts in the application, and each alert covers every certificate in the application for one event. To alert on certificates across Certificate Manager, including ones outside an application, create an alert under [**Settings** > **Alerts**](/documentation/platform/pki/settings/alerts).

## Alert events

<CardGroup cols={2}>
  <Card title="Expiration" icon="clock">
    Notifies a set number of days before a certificate expires.
  </Card>
  <Card title="Issuance" icon="award">
    Notifies when Infisical issues a certificate in the application.
  </Card>
  <Card title="Renewal" icon="rotate-cw">
    Notifies when a certificate is renewed.
  </Card>
  <Card title="Revocation" icon="ban">
    Notifies when a certificate is revoked.
  </Card>
</CardGroup>

Infisical checks expiration alerts once a day. Issuance, renewal, and revocation alerts are sent within seconds of the event. Importing a certificate into the application doesn't trigger an Issuance alert, but expiration and revocation alerts still cover imported certificates.

## Prerequisites

- Permission to create alerts in the application (the **Create** action on **PKI Alerts**)
- For email alerts, recipients who are members of Certificate Manager, or addresses on one of your organization's [verified email domains](/documentation/platform/email-domain)

## Create an alert

<Steps>
  <Step>
    Go to **Certificate Manager** > **Applications** and select your application.
  </Step>
  <Step>
    Select the **Settings** tab, then select **Create Alert** in the **Alerts** section.
  </Step>
  <Step>
    Choose the **Alert Type**, then enter an **Alert Name** and an optional **Description**.
  </Step>
  <Step>
    For an expiration alert, enter **Alert Before** as a number and a unit, for example `30d` or `2w`, up to 365 days. Turn on **Repeat daily until expiry** to get a reminder every day. See [how often expiration alerts repeat](#faq). Select **Continue**.
  </Step>
  <Step>
    Select **Add Channel** and choose where to send notifications. You can add up to 10 channels. See [Notification channels](#notification-channels). To check a channel, select **Send test** on it. Select **Continue**.
  </Step>
  <Step>
    Check the summary on the **Review** step, then select **Create Alert**.
  </Step>
</Steps>

You can create more than one alert for the same event, each with its own channels. For example, send expiration alerts 30 days ahead by email and 7 days ahead to PagerDuty.

## Notification channels

| Channel | Sends to |
|---------|----------|
| **Email** | Certificate Manager members, or any address on one of your organization's verified email domains |
| **[Slack](/documentation/platform/pki/applications/alerting/slack-alerts)** | A Slack channel through an Incoming Webhook |
| **[PagerDuty](/documentation/platform/pki/applications/alerting/pagerduty-alerts)** | A PagerDuty service through Events API v2 |
| **[Webhook](/documentation/platform/pki/applications/alerting/webhook-alerts)** | Any HTTPS endpoint, with an optional signature |

After an alert runs, the **Last Run** column in the **Alerts** section shows whether every channel delivered, and hovering over a failed run shows the error.

<Note>
  Slack, PagerDuty, and webhook channels depend on your plan. If your plan doesn't include them, Infisical rejects the new channel and asks you to upgrade. Channels you already added keep sending.
</Note>

## FAQ

<AccordionGroup>
  <Accordion title="Who receives email alerts?">
    The addresses you enter on the email channel. An address that belongs to a Certificate Manager member only receives alerts while that person is still a member. Any other address has to be on one of your organization's [verified email domains](/documentation/platform/email-domain) when you add it.
  </Accordion>
  <Accordion title="How often does an expiration alert notify about the same certificate?">
    The alert repeats until the certificate is renewed or expires. How often it repeats depends on how many days before expiry the alert starts:

    | Days before expiry | Repeats every |
    |--------------------|---------------|
    | 7 or fewer | Day |
    | 8 to 30 | 2 days |
    | 31 to 90 | 7 days |
    | More than 90 | 30 days |

    If you turn on **Repeat daily until expiry**, the alert repeats every day.
  </Accordion>
  <Accordion title="What happens to an alert when I delete its application?">
    Infisical deletes the application's alerts and their channels along with the application.
  </Accordion>
</AccordionGroup>
