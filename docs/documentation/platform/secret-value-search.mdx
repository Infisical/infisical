---
title: "Secret value search"
description: "Find every project, environment, and path where a secret value is stored."
---

Secret value search finds every secret in your organization whose value exactly matches a value you enter, and shows the project, environment, and path of each match. It searches every [Secrets Management project](/documentation/platform/secrets-mgmt/project) in the organization, including projects you aren't a member of.

Use it when a credential leaks. Paste the leaked value to see every place it's stored, so you can rotate or replace each copy instead of only the one you knew about.

## Prerequisites

- An organization role with the **Search All Secret Values** permission under **Secrets Management Insights**, such as the built-in **Admin** role (to grant it to another role, see [organization role-based access controls](/documentation/platform/access-controls/role-based-access-controls#organization-level-access-controls))

## Enable secret value search

Infisical has to process every secret value in the organization before a search can return complete results, so someone with the permission turns secret value search on once for the whole organization.

To enable secret value search:

<Steps>
  <Step>
    In your organization, go to **Secrets Management** > **Projects**.
  </Step>
  <Step>
    Select the search box, then select **Search by secret value**.
  </Step>
  <Step>
    Select **Enable Secret Value Search**.
  </Step>
</Steps>

The panel shows how many projects are ready while Infisical processes the organization's secrets. You can leave the page while it runs. When every project is ready, the panel shows the search box.

Once secret value search is on, it stays on, and Infisical keeps it up to date as secrets are created and changed. Turning it on also turns on the organization-wide [duplicated secrets](/documentation/platform/insights#duplicated-secrets-across-projects) card on the Insights page.

## Search for a secret value

To search for a secret value:

<Steps>
  <Step>
    In your organization, go to **Secrets Management** > **Projects**.
  </Step>
  <Step>
    Select the search box, then select **Search by secret value**.
  </Step>
  <Step>
    Paste the full secret value, then press `Enter` or select **Search**. The search doesn't run as you type.

    The value stays masked while you type. To check what you pasted, select the eye icon beside the box. To add a line break to a multi-line value, press `Shift+Enter`.
  </Step>
  <Step>
    Review the matches. Each row shows the **Project**, **Secret Key**, **Environment**, and **Path** of a secret that holds the value.

    To open a match, hover over its row and select the arrow icon. The project's secrets overview opens at that path, filtered to that environment.

    If you aren't a member of the match's project, the arrow icon is disabled.
  </Step>
</Steps>

Closing the panel clears the value and the results.

## How values are matched

A secret matches only if its value is identical to the value you enter:

- Part of a value doesn't match (searching `sk_live_abc` doesn't find `sk_live_abc123`)
- A value that differs in case or whitespace, including a trailing newline, doesn't match
- Only each secret's current value is searched, not its [previous versions](/documentation/platform/secret-versioning)
- [Personal overrides](/documentation/platform/secrets-mgmt/project#personal-overrides) aren't searched
- Secrets in projects or environments that are waiting to be deleted aren't searched

A search returns at most 1,000 matches. If a value has more matches than that, the panel says it's showing the first 1,000.

## Audit logs

Infisical records each search in the organization's [audit logs](/documentation/platform/audit-logs) as a **Search Secrets by Value** event, with the number of matches. The event doesn't include the value you searched for. Turning on secret value search is recorded as an **Enable Org-Wide Secret Value Tracking** event.
