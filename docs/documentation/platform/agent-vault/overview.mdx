---

Infisical Agent Vault brokers credentials for the AI agents you run in your own infrastructure. Your agents reach APIs, MCP servers, databases, and SSH servers through an Agent Vault proxy. The proxy adds the real credentials to each request, so the agents never see them.

<Tip>
  Visual learner? Watch an [introduction to Agent Vault](https://www.youtube.com/watch?v=73JY9sQ0_b0).
</Tip>
