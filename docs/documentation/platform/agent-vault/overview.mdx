Agent Vault lets an AI agent call GitHub, Slack, an LLM provider, or any other HTTP API without holding the credential for it. The agent's traffic goes through an Agent Vault proxy, and the proxy attaches the real credential on the way out. If the agent is compromised, there is no key to steal.

```text
+-----------+                 +-------------------+                +------------------+
| AI agent  | --------------> | Agent Vault proxy | -------------> |  api.github.com  |
+-----------+  session token  +-------------------+  request with  |  api.slack.com   |
                                       |             the credential |  ...             |
                                       | checks what this session   +------------------+
                                       | may reach
                                       v
                                +-------------+
                                |  Infisical  |
                                +-------------+
```

## How it works

1. An admin creates an access bundle: a set of connections, each naming the hosts of one API and the credential to attach.
2. The admin grants the bundle to the people, machine identities, or groups that may run agents with it.
3. Someone with the grant mints a session, a token that carries the bundle and an expiry.
4. The agent starts with the session token and the proxy's address. Every request it makes to a covered host leaves the proxy with the credential attached.
5. Access is checked while the agent runs. Revoke the session or the grant, and the agent stops getting credentials within a minute.
