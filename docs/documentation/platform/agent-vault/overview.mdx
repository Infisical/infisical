Infisical Agent Vault brokers credentials for the AI agents you run in your own infrastructure. Your agents call HTTP APIs and MCP servers through an Agent Vault proxy, which attaches the real credentials so the agents never see them.

## Concepts

<CardGroup cols={2}>
  <Card title="Access bundles" icon="box" href="/documentation/platform/agent-vault/access-bundles">
    Lists of services that AI agents can access during a session.
  </Card>
  <Card title="Services" icon="plug" href="/documentation/platform/agent-vault/services">
    Anything an AI agent talks to during a session, such as an API or an MCP server.
  </Card>
  <Card title="Variables" icon="braces" href="/documentation/platform/agent-vault/variables">
    Values you store once and use in any service in Agent Vault.
  </Card>
  <Card title="Skills" icon="book-open-text" href="/documentation/platform/agent-vault/skills">
    Instructions you keep in Agent Vault and install for agents you start with an access bundle.
  </Card>
  <Card title="Sessions" icon="monitor" href="/documentation/platform/agent-vault/sessions">
    Time-bound grants that let AI agents access services without holding real credentials.
  </Card>

  <Card title="Create sessions with the API" icon="key-round" href="/documentation/platform/agent-vault/sessions-api">
