Infisical Agent Vault is an access layer for AI agents. It securely equips agents with what they need to do work, including access to the services they call: LLM providers, GitHub, Slack, and more.

## Concepts

<CardGroup cols={2}>
  <Card title="Access bundles" icon="box" href="/documentation/platform/agent-vault/access-bundles">
    Lists of services that AI agents can access during a session.
  </Card>
  <Card title="Services" icon="plug" href="/documentation/platform/agent-vault/services">
    External APIs that an AI agent can securely call during a session.
  </Card>
  <Card title="Variables" icon="braces" href="/documentation/platform/agent-vault/variables">
    Values you store once in an access bundle and use in any of its services.
  </Card>
  <Card title="Sessions" icon="monitor" href="/documentation/platform/agent-vault/sessions">
    Time-bound grants that let AI agents access services without holding real credentials.
  </Card>
  <Card title="Create sessions with the CLI" icon="calendar-clock" href="/documentation/platform/agent-vault/sessions-cli">
    Start an agent from cron, a container, or CI, with a new session for each run.
  </Card>
  <Card title="Create sessions with the API" icon="key-round" href="/documentation/platform/agent-vault/sessions-api">
    Create a session for each agent run from your own code.
  </Card>
  <Card title="Session logs" icon="list" href="/documentation/platform/agent-vault/session-logs">
    A record of every request an AI agent makes, stored encrypted in your own Amazon S3 bucket.
  </Card>
  <Card title="Proxies" icon="server" href="/documentation/platform/agent-vault/proxies">
    Forward proxies that intercept an AI agent's requests and attach real credentials on the way out.
  </Card>
  <Card title="Access control" icon="shield-half" href="/documentation/platform/agent-vault/access-control">
    Understand how permissions work in Agent Vault.
  </Card>
</CardGroup>
