---
title: "Services"
description: "Anything an AI agent talks to during a session, such as an API or an MCP server."
---

A service is something your agent talks to during a [session](/documentation/platform/agent-vault/sessions), such as an API or an MCP server, that Agent Vault brokers credentials for. You store the real credential on the service, and the [proxy](/documentation/platform/agent-vault/proxies) adds it to the agent's requests to that service. The agent can authenticate to the service without ever holding the credential.

You can configure services within an [access bundle](/documentation/platform/agent-vault/access-bundles). For example, you might create a **code-review** access bundle and add services for Slack, GitHub, and Anthropic:
