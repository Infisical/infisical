Mention the coding agent in a Slack channel, and it answers questions about your repo, or makes the change you ask for on a branch and opens a pull request. This version runs the agent and an Agent Vault proxy as two containers, started with Docker Compose. The agent holds no API keys.

To run it on a virtual machine instead, see [Coding Slack agent on a virtual machine](/documentation/platform/agent-vault/guides/coding-slack-agent-vm).

## How it works

1. A Slack bridge receives each mention and runs [Claude Code](/documentation/platform/agent-vault/guides/claude-code) with the message, in a clone of your repo that it keeps between messages.
2. Claude Code changes the code, runs the repo's tests, and uses `git` and `gh` to push a branch and open a pull request.
3. Every request goes through the Agent Vault [proxy](/documentation/platform/agent-vault/proxies), which attaches the real credential for Anthropic, GitHub, and Slack, and blocks hosts outside the agent's [access bundle](/documentation/platform/agent-vault/access-bundles).
## What you need

- An Agent Vault project where you have the Admin role
- A Slack workspace where you can create apps
- A GitHub repo with at least one commit
- Docker with Compose, or a container platform such as Amazon ECS or Render
