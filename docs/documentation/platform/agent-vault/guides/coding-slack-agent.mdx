## How it works

1. A Slack bridge receives each mention and runs the agent with the message, in a clone of your repo that it keeps between messages.
2. The agent changes the code, runs the repo's tests, and uses `git` and `gh` to push a branch and open a pull request.
3. Every request goes through an Agent Vault [proxy](/documentation/platform/agent-vault/proxies), which attaches the real credential for Anthropic, GitHub, and Slack, and blocks hosts outside the agent's [access bundle](/documentation/platform/agent-vault/access-bundles).

## What you need

- An Agent Vault project where you have the Admin role
- A Slack workspace where you can create apps
- A GitHub repo with at least one commit
- Somewhere to run it: Docker with Compose, or a Debian or Ubuntu virtual machine
