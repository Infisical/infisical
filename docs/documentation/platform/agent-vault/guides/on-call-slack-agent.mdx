The on-call agent is a Slack agent that investigates production errors. When you mention it in a channel, it reads the error in Sentry, traces it to the code and the commit that caused it, and proposes a fix. When you ask, it opens a pull request with the fix or files a GitHub issue.

## How it works

1. A Slack bridge receives each mention and runs the agent with the message, in a clone of your repository. The reference architecture uses Claude Code as the agent.
2. The agent reads the error from the Sentry API, and uses `git` and `gh` to find the commit, and to open a pull request or file an issue when you ask.
3. Every request goes through an Agent Vault [proxy](/documentation/platform/agent-vault/proxies), which attaches the real credential for Anthropic, GitHub, Sentry, and Slack, and blocks hosts outside the agent's [access bundle](/documentation/platform/agent-vault/access-bundles).

## Prerequisites

- An [Agent Vault project](/documentation/platform/agent-vault/projects) where you have the [**Admin** role](/documentation/platform/agent-vault/access-control#product-membership)
- A Slack workspace where you can [create apps](https://api.slack.com/apps)
- A [Sentry](https://sentry.io/) project, and a [GitHub](https://github.com/) repository with at least one commit
- [Docker](https://docs.docker.com/get-started/get-docker/) with Docker Compose, or a Debian or Ubuntu virtual machine
