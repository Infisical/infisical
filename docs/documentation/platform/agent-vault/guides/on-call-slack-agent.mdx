Mention the on-call agent in a Slack channel, and it reads the error in Sentry, traces it to the code and the commit that caused it, and proposes a fix. When you ask, it opens a pull request with the fix or files a GitHub issue.

## How it works

1. A Slack bridge receives each mention and runs the agent with the message, in a clone of your repo.
2. The agent reads the error from the Sentry API, and uses `git` and `gh` to find the commit, and to open a pull request or file an issue when you ask.
3. Every request goes through an Agent Vault [proxy](/documentation/platform/agent-vault/proxies), which attaches the real credential for Anthropic, GitHub, Sentry, and Slack, and blocks hosts outside the agent's [access bundle](/documentation/platform/agent-vault/access-bundles).

## What you need

- An Agent Vault project where you have the Admin role
- A Slack workspace where you can create apps
- A Sentry project, and a GitHub repo with at least one commit
- Somewhere to run it: Docker with Compose, or a Debian or Ubuntu virtual machine
