Mention the recruiting agent in your hiring team's Slack channel, and it answers questions about open jobs, candidates, and where each candidate is in the pipeline, from Ashby. This version runs the agent and an Agent Vault proxy as two containers, started with Docker Compose. The agent holds no API keys.

To run it on a virtual machine instead, see [Recruiting Slack agent on a virtual machine](/documentation/platform/agent-vault/guides/recruiting-slack-agent-vm).

## How it works

1. A Slack bridge receives each mention and runs [Claude Code](/documentation/platform/agent-vault/guides/claude-code) with the message.
2. Claude Code reads Ashby through Ashby's [MCP server](/documentation/platform/agent-vault/mcp-servers), signed in with OAuth. The proxy hides every Ashby tool except the read tools you allow, so the agent can't change anything.
3. Every request goes through the Agent Vault [proxy](/documentation/platform/agent-vault/proxies), which attaches the real credential for Anthropic, Ashby, and Slack, and blocks hosts outside the agent's [access bundle](/documentation/platform/agent-vault/access-bundles).
## What you need

- An Agent Vault project where you have the Admin role
- A Slack workspace where you can create apps, and a private channel for your hiring team
- An Ashby account whose access matches what the hiring team may see
- Docker with Compose, or a container platform such as Amazon ECS or Render
