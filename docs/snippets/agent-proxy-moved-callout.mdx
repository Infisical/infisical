<Warning>
  [Agent Vault](/documentation/platform/agent-vault/overview) replaces Agent Proxy. You can't create new proxied services, so use Agent Vault for every new setup. To start, follow the [Agent Vault quickstart](/documentation/platform/agent-vault/quickstart).

  Your existing proxied services keep working, and you can still edit and delete them. Infisical will remove proxied services in a future release, so set up the same services in Agent Vault before then.
</Warning>
