- **Name**: A descriptive name for the connection, such as `deno-deploy-prod`
- **Description** (optional): A note for future reference
- **Method**: **Personal Access Token** (selected by default)
- **Access Token**: The token you copied when you [created the Deno Deploy access token](#step-1-create-a-deno-deploy-access-token)
- **Organization ID** (optional): The Deno Deploy organization this token belongs to. Infisical stores it with the connection and doesn't send it to Deno Deploy
