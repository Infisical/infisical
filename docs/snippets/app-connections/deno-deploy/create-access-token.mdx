<Steps>
    <Step>
        Open the [Deno Deploy dashboard](https://dash.deno.com) and select the organization whose apps you want Infisical to sync secrets to.
    </Step>
    <Step>
        Go to **Settings**, then open **Access Tokens**.
    </Step>
    <Step>
        Select **Create Token**, give the token a name, and copy it. Deno Deploy shows the token only once, and you need it to create the connection in Infisical. The token starts with `ddo_`.
    </Step>
</Steps>
