- **Name**: A descriptive name for the connection, such as `convex-prod`
- **Description** (optional): A note for future reference
- **Method**: **Personal Access Token** (selected by default)
- **Access Token**: The token you copied when you [created the personal access token](/integrations/app-connections/convex#create-a-personal-access-token-in-convex)
- **Instance URL** (optional): The Convex API URL (leave this empty to use `https://api.convex.dev`)
