<Steps>
    <Step>
        In the [Convex Dashboard](https://dashboard.convex.dev), select your profile avatar, then select **Profile Settings**.

        ![Profile Settings](/images/app-connections/convex/01-profile-settings.png)
    </Step>
    <Step>
        Under **Personal Access Tokens**, select **+ Create Token**.

        ![Create Token](/images/app-connections/convex/02-create-token.png)
    </Step>
    <Step>
        Enter a **Token Name**, such as `infisical`, pick an **Expiration**, then select **Create**.

        <Warning>
            If the token expires, Infisical can't use the connection until you replace the token. Set a long expiration, or select **No expiration**.
        </Warning>

        ![Fill and Create Token](/images/app-connections/convex/03-fill-and-create-token.png)
    </Step>
    <Step>
        Copy the token and store it securely. Convex shows it only once, and you need it to create the connection in Infisical.

        ![Copy Token](/images/app-connections/convex/04-copy-token.png)
    </Step>
</Steps>
