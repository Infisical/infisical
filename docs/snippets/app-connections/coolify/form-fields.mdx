- **Name**: A descriptive name for the connection; it must be slug-friendly
- **Description** (optional): A note for future reference
- **Gateway**: The Gateway or Gateway pool to route requests through if your Coolify instance isn't reachable from the internet; otherwise leave it as **Internet Gateway**
- **Method**: **API Token**, the only method the connection supports
- **Instance URL**: `https://app.coolify.io` for Coolify Cloud (filled in by default), or the URL of your self-hosted Coolify dashboard, such as `https://coolify.example.com`
- **Coolify API Token**: The token you copied when [creating a Coolify API token](#step-1-create-a-coolify-api-token)
