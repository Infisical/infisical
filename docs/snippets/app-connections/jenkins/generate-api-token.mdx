<Steps>
    <Step>
        Log in to Jenkins as the user from the [prerequisites](#prerequisites). Select your name in the top-right corner, then select **Security**. On older Jenkins versions, select **Configure** instead.
    </Step>
    <Step>
        Under **API Token**, select **Add new Token**, enter a name that identifies the token, such as `infisical`, then select **Generate**.

        <Note>
            Use an API token, not the user's password. If you connect with a password, Jenkins rejects every change Infisical makes to credentials.
        </Note>
    </Step>
    <Step>
        Copy the token and store it securely. Jenkins shows it only once.
    </Step>
</Steps>
