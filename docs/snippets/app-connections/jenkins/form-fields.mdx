- **Name**: A descriptive name for the connection; it must be slug-friendly
- **Description** (optional): A note for future reference
- **Gateway**: The Gateway or Gateway pool to route requests through if your Jenkins instance isn't reachable from the internet; otherwise leave it as **Internet Gateway**
- **Method**: **API Token**, the only method the connection supports
- **Jenkins Instance URL**: The URL of your Jenkins instance, including the path Jenkins is served under if it has one, such as `https://ci.example.com/jenkins`
- **Jenkins Username**: The username of the Jenkins user that owns the API token
- **Jenkins API Token**: The token you copied when [generating a Jenkins API token](#step-1-generate-a-jenkins-api-token)
