<Tabs>
    <Tab title="Client Secret">
        - **Name**: A descriptive name for the connection
        - **Description** (optional): A note for future reference
        - **Method**: **Client Secret**
        - **Storage Account Name**: The name of the storage account, which is 3 to 24 lowercase letters and numbers
        - **Tenant ID**: The **Directory (tenant) ID** you copied from the app registration
        - **Client ID**: The **Application (client) ID** you copied from the app registration
        - **Client Secret**: The client secret's **Value** you copied from the app registration
    </Tab>
    <Tab title="Access Key">
        - **Name**: A descriptive name for the connection
        - **Description** (optional): A note for future reference
        - **Method**: **Access Key**
        - **Storage Account Name**: The name of the storage account, which is 3 to 24 lowercase letters and numbers
        - **Account Key**: The access key you copied from the storage account
    </Tab>
</Tabs>
