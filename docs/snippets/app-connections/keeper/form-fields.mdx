- **Name**: A descriptive name for the connection, such as `keeper-prod`
- **Description** (optional): A note for future reference
- **Instance URL**: The base URL of your Commander Service Mode instance, such as `https://keeper.company.com`, without an `/api` path
- **API Key**: The key you copied when you [set up Keeper Commander](/integrations/app-connections/keeper#step-1-set-up-keeper-commander)
