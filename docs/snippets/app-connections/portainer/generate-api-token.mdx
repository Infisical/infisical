<Steps>
    <Step>
        Log in to your Portainer instance, select the user icon in the top-right corner, then select **My account**.
    </Step>
    <Step>
        Scroll to the **Access tokens** section and select **Add access token**.
    </Step>
    <Step>
        Enter a **Description** that identifies the token, such as `infisical`, then select **Add access token**.

        <Note>
            An access token inherits the permissions of the user that created it, so create it as a user who can read the environments and update the stacks you plan to sync to.
        </Note>
    </Step>
    <Step>
        Copy the token and store it securely. Portainer shows it only once.
    </Step>
</Steps>
