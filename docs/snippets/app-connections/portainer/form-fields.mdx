- **Name**: A descriptive name for the connection; it must be slug-friendly
- **Description** (optional): A note for future reference
- **Gateway**: The Gateway or Gateway pool to route requests through if your Portainer instance isn't reachable from the internet; otherwise leave it as **Internet Gateway**
- **Method**: **API Token**, the only method the connection supports
- **Portainer Instance URL**: The URL of your Portainer instance, such as `https://portainer.example.com`
- **Portainer API Token**: The token you copied when [generating a Portainer API token](/integrations/app-connections/portainer#step-1-generate-a-portainer-api-token)
