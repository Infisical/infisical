<Steps>
    <Step title="Open workspace settings" titleSize="h3">
        In Databricks, open the dropdown in the top right and select **Settings**.

        ![Workspace Settings Page](/images/app-connections/databricks/workspace-settings.png)
    </Step>
    <Step title="Open service principals" titleSize="h3">
        Under **Identity & Access**, select **Manage** in the **Service Principals** section.

        ![Manage Service Principals](/images/app-connections/databricks/manage-service-principals.png)
    </Step>
    <Step title="Add a service principal" titleSize="h3">
        Select **Add Service Principal**, then **Add New**, and create a service principal for Infisical.

        ![Add Service Principal](/images/app-connections/databricks/add-service-principal.png)
        ![Create Service Principal](/images/app-connections/databricks/create-service-principal.png)
    </Step>
    <Step title="Generate a secret" titleSize="h3">
        Open the new service principal, select the **Secrets** tab, and select **Generate Secret**. Save the **Client ID** and **Secret** for the Infisical form.

        ![Generate Secret](/images/app-connections/databricks/service-principal-secrets.png)
        ![Copy IDs](/images/app-connections/databricks/service-principal-ids.png)
    </Step>
    <Step title="Grant rotation permissions" titleSize="h3">
        The Infisical service principal needs to manage the secrets of every service principal whose secrets you want to rotate.

        1. Navigate to **Settings > Identity & Access > Groups** and select the admin group (typically named `admins` or `workspace-admins`). Select **Add** and pick the Infisical service principal.

            ![Admin Group](/images/app-connections/databricks/admin-group.png)
            ![Add to Admin Group](/images/app-connections/databricks/add-to-admin-group.png)
            ![Add to Admin Group Modal](/images/app-connections/databricks/add-to-admin-group-form.png)

        2. For every service principal whose secrets you want to rotate, open **Settings > Identity & Access > Service Principals**, select the target, open its **Permissions** tab, and select **Grant access**.

            ![Select Target Service Principal](/images/app-connections/databricks/select-target-service-principal.png)
            ![Permissions Tab](/images/app-connections/databricks/permissions-tab.png)

        3. In **User, Group or Service Principal**, select the Infisical service principal. In **Permission**, select **Manage**. Select **Save**. Repeat for every target.

            ![Assign Manage Permission](/images/app-connections/databricks/assign-manage-permission.png)
    </Step>
</Steps>
