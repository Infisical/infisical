    </Tab>

        - **Name**: A descriptive name for the connection
        - **Description** (optional): A note for future reference
        - **Method**: **Access Key**
        - **Access Key ID**: The access key ID you copied from the IAM user
        - **Secret Access Key**: The secret access key you copied from the IAM user
    </Tab>
