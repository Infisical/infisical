<Tip>
  **Using an AI coding tool?** Connect it to the Infisical resources described below for better results.

  Install the Infisical skills to provide the tool with information about the platform's structure, services, and conventions:

  ```bash
  npx skills add Infisical/ai-skills
  ```

  Then add the Infisical MCP server to give the tool access to the current documentation. See [Set up with AI](https://infisical.com/docs/documentation/getting-started/set-up-with-ai) for the full setup instructions.
</Tip>
