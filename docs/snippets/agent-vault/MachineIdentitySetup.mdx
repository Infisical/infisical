<Steps>
  <Step>
    If the project has no role for agents yet, [create a custom role](/documentation/platform/agent-vault/access-control#create-a-custom-role) from the **Service User** template, and give it **Use** on the access bundle the agent uses.
  </Step>
  <Step>
    In your Agent Vault project, go to **Access Control** > **Machine Identities** and select **Add Machine Identity**.
  </Step>
  <Step>
    On the **Create New** tab, enter a **Name**, pick that role in **Roles**, then select **Create**. Infisical creates the machine identity with [Universal Auth](/documentation/platform/identities/universal-auth) and opens its page.

    <Frame>
      <img src="/images/platform/agent-vault/machine-identity-create.png" alt="The Create New tab of the Add Machine Identity to Project panel, with ci-runner-2 as the name and the Release Engineers role picked" />
    </Frame>

    <Tip>
    To use a machine identity that already exists in your organization, select the **Assign Existing** tab instead.
    </Tip>
  </Step>
  <Step>
    On the machine identity's page, select **Universal Auth** under **Authentication**. Copy the **Client ID**, then select **Add Client Secret** and copy the client secret.
  </Step>
</Steps>
