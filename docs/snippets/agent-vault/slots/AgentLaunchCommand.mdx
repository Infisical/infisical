<AgentVaultBranch agent="hermes">
  Hermes reads its API keys from `~/.hermes/.env`, and it won't start without them. If the service you added holds one of those keys, such as your model provider's key, replace the key's value in that file with a placeholder, such as `agent-vault-openai`. The proxy attaches the real key, so Hermes only needs a value it accepts. If the service uses a [substitution](/documentation/platform/agent-vault/http-apis#substitutions), use the exact value you entered in **Replace** instead.

  <Warning>
    Hermes treats some values as an unset key, including `dummy`, `placeholder`, `changeme`, `none`, and values made only of `x` characters, such as `sk-xxxx`. If you use one of these values, Hermes reports the key as missing instead of sending it to the proxy.
  </Warning>

  Then, on the machine that will run the agent, paste the command you copied in the previous step. Replace `<proxy-host>` with the address of the proxy's host, and `<agent-command>` with `hermes --tui`:

  ```bash
  infisical agent-vault run --session-token <session-token> --proxy <proxy-host>:17323 -- hermes --tui
  ```
</AgentVaultBranch>

<AgentVaultBranch agent="openclaw">
  If the service you added holds your model provider's key, OpenClaw needs a placeholder in its place. Onboarding saves the key in OpenClaw's credential store. Run `openclaw models auth list` to find the saved profile, then remove it with `openclaw models auth logout <profile-id>`.

  Then create `~/.openclaw/.env`, or add to it if it already exists, with a placeholder for the key, such as `OPENAI_API_KEY=agent-vault-openai`. The proxy attaches the real key, so OpenClaw only needs a value to send. If the service uses a [substitution](/documentation/platform/agent-vault/http-apis#substitutions), use the exact value you entered in **Replace** instead.

  Then, on the machine that will run the agent, paste the command you copied in the previous step. Replace `<proxy-host>` with the address of the proxy's host, and `<agent-command>` with `openclaw tui --local`, which starts OpenClaw's terminal UI without a separate Gateway:

  ```bash
  infisical agent-vault run --session-token <session-token> --proxy <proxy-host>:17323 -- openclaw tui --local
  ```
</AgentVaultBranch>
