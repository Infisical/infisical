## Description

The `ssh` command group issues short-lived SSH certificates from Infisical SSH certificate templates and manages host enrollment, so machines can authenticate through Infisical-issued certificates instead of long-lived keys.

Credentials can be issued for your logged-in user, or non-interactively with a machine identity via the `--token` flag.

## Subcommands & flags

<AccordionGroup>
<Accordion title="infisical ssh issue-credentials" defaultOpen="true">
  Issue SSH credentials (a keypair and certificate) against a certificate template.

```bash
infisical ssh issue-credentials \
  --certificateTemplateId=<template-id> \
  --principals=deploy \
  --ttl=8h \
  --addToAgent
```

| Flag                    | Description                                                                                                         |
| ----------------------- | ------------------------------------------------------------------------------------------------------------------- |
| `--token`               | Issue SSH credentials using a machine identity access token                                                          |
| `--certificateTemplateId` | The ID of the SSH certificate template to issue SSH credentials for                                                |
| `--principals`          | The principals to issue SSH credentials for                                                                          |
| `--keyAlgorithm`        | The key algorithm to issue SSH credentials for (`RSA_2048`, `RSA_4096`, `EC_prime256v1`, `EC_secp384r1`; default `RSA_2048`) |
| `--certType`            | The cert type to issue SSH credentials for (default `user`)                                                          |
| `--ttl`                 | The TTL to issue SSH credentials for                                                                                 |
| `--keyId`               | The key ID that the created certificate should have                                                                  |
| `--outFilePath`         | The path to write the SSH credentials to. If not provided, credentials are saved to the current working directory     |
| `--addToAgent`          | Add issued SSH credentials to the SSH agent                                                                          |
</Accordion>

<Accordion title="infisical ssh sign-key">
  Sign an existing SSH public key against a certificate template.

```bash
infisical ssh sign-key \
  --certificateTemplateId=<template-id> \
  --publicKeyFilePath=~/.ssh/id_ed25519.pub
```

| Flag                    | Description                                                                                                     |
| ----------------------- | --------------------------------------------------------------------------------------------------------------- |
| `--token`               | Issue the SSH certificate using a machine identity access token                                                  |
| `--certificateTemplateId` | The ID of the SSH certificate template to issue the certificate for                                            |
| `--publicKey`           | The public key to sign (inline)                                                                                  |
| `--publicKeyFilePath`   | The file path to the public key file to sign                                                                     |
| `--outFilePath`         | The path to write the certificate to (default: next to the public key, or the current working directory)          |
| `--principals`          | The principals that the certificate should be signed for                                                         |
| `--certType`            | The cert type for the created certificate (default `user`)                                                       |
| `--ttl`                 | The TTL for the created certificate                                                                              |
| `--keyId`               | The key ID that the created certificate should have                                                              |
</Accordion>

<Accordion title="infisical ssh connect">
  Connect to an SSH host using issued credentials.

```bash
infisical ssh connect --hostname=web-01 --login-user=deploy
```

| Flag                     | Description                                                                                                |
| ------------------------ | ---------------------------------------------------------------------------------------------------------- |
| `--token`                | Use a machine identity access token                                                                         |
| `--hostname`             | Hostname of the SSH host to connect to                                                                       |
| `--login-user`           | Login user for the SSH connection                                                                            |
| `--write-host-ca-to-file` | Write the Host CA public key to `~/.ssh/known_hosts` if not already present (default `true`)                 |
| `--out-file-path`        | The path to write the SSH credentials to. If not provided, credentials are added to the SSH agent and an interactive connection is started |
</Accordion>

<Accordion title="infisical ssh add-host">
  Register a new SSH host with Infisical and optionally configure its SSH daemon.

```bash
sudo infisical ssh add-host \
  --projectId=<project-id> \
  --hostname=web-01.internal \
  --configure-sshd
```

| Flag                       | Description                                                                                    |
| -------------------------- | ---------------------------------------------------------------------------------------------- |
| `--token`                  | Use a machine identity access token                                                             |
| `--projectId`              | Project ID the host belongs to (required)                                                       |
| `--hostname`               | Hostname of the SSH host (required)                                                             |
| `--alias`                  | Alias for the SSH host                                                                          |
| `--write-user-ca-to-file`  | Write the User CA public key to `/etc/ssh/infisical_user_ca.pub`                                 |
| `--user-ca-out-file-path`  | Custom file path to write the User CA public key (default `/etc/ssh/infisical_user_ca.pub`)      |
| `--write-host-cert-to-file` | Write the SSH host certificate to `/etc/ssh/ssh_host_<type>_key-cert.pub`                       |
| `--configure-sshd`         | Update `TrustedUserCAKeys`, `HostKey`, and `HostCertificate` in `/etc/ssh/sshd_config`           |
| `--force`                  | Force overwrite of existing certificate files written by the two `--write-*-` flags above         |
</Accordion>
</AccordionGroup>
