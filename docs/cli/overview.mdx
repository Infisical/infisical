The Infisical CLI allows you to interact with the Infisical platform from your terminal.

<Warning>
  If you installed the CLI on Linux from the Cloudsmith package repository, [move to `artifacts-cli.infisical.com`](/cli/cloudsmith-migration). Cloudsmith stopped serving the CLI on September 16, 2026, so machines still pointed at it can't install or upgrade the CLI.
</Warning>
