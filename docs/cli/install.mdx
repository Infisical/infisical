<Warning>
  If you installed the CLI on Linux from the Cloudsmith package repository, move to `artifacts-cli.infisical.com`. Cloudsmith stopped serving the CLI on September 16, 2026, so machines still pointed at it can't install or upgrade the CLI. See [Migrate off Cloudsmith](/cli/cloudsmith-migration).
</Warning>

Install the CLI with the package manager for your operating system:

<InstallCli />

Check that the installation worked:

```bash
infisical --version
```

If you install the CLI in production, such as on a server or in a container image, pin a specific version so every reinstall gets the same one. The [CLI releases](https://github.com/Infisical/cli/releases) list every version.
