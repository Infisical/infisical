A Snowflake connection authenticates Infisical to your Snowflake account as a Snowflake user, with a [programmatic access token](https://docs.snowflake.com/en/user-guide/programmatic-access-tokens) that you generate for that user. Infisical can then sync secrets into a Snowflake schema and rotate the key pairs of Snowflake users.

<Note>
    This guide only authenticates Infisical with Snowflake. Once the app connection is ready, you can [use it to set up integrations](#step-3-configure-integrations).
</Note>

## Prerequisites

- A [Snowflake account](https://app.snowflake.com/) where you can create users, roles, and network policies, such as with the `ACCOUNTADMIN` role

## Step 1: Create a Snowflake user and programmatic access token

Infisical needs a Snowflake user with a programmatic access token, a network policy, and a role with privileges for the integration you'll set up.

## Step 2: Create the app connection

Next, create the app connection in Infisical.

<View title="Organization-level">
    <Steps>
        <Step>
            In the sidebar, select **Organization Settings**, then open the **App Connections** tab.

            ![App Connections Tab](/images/app-connections/general/add-connection.png)
        </Step>
        <Step>
            Select **+ Add Connection** and choose **Snowflake Connection**.

            ![Select Snowflake Connection](/images/app-connections/snowflake/snowflake-app-connection-option.png)
        </Step>
        <Step>
            Fill out the form's fields:

            <ConnectionFormFields />

            Then, select **Connect to Snowflake**.

            ![Snowflake Connection Form](/images/app-connections/snowflake/snowflake-app-connection-form.png)
        </Step>
    </Steps>
</View>

<View title="Project-level">
    <Steps>
        <Step>
            In your Secrets Manager project, select **Integrations** from the sidebar, then open the **App Connections** tab.
        </Step>
        <Step>
            Select **Add Connection** and choose **Snowflake Connection**.
        </Step>
        <Step>
            Fill out the form's fields:

            <ConnectionFormFields />

            Then, select **Connect to Snowflake**.
        </Step>
    </Steps>
</View>

When you submit the form, Infisical signs in to Snowflake with the account identifier, username, and token, and shows Snowflake's error if the sign-in fails.

<Check>
    Your Snowflake app connection is ready to use.
</Check>

<Accordion title="Create the connection with the API">
    Send the account identifier, username, and programmatic access token to the create endpoint for Snowflake connections. The token goes in the `password` field.

    ```bash
    curl --request POST \
      --url https://app.infisical.com/api/v1/app-connections/snowflake \
      --header 'Authorization: Bearer <access-token>' \
      --header 'Content-Type: application/json' \
      --data '{
        "name": "my-snowflake-connection",
        "method": "username-and-token",
        "credentials": {
          "account": "<org-name>-<account-name>",
          "username": "<snowflake-username>",
          "password": "<programmatic-access-token>"
        }
      }'
    ```
</Accordion>
