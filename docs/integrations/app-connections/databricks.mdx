A Databricks connection authenticates Infisical to your Databricks workspace using a [service principal](https://docs.databricks.com/en/admin/users-groups/service-principals.html) that you create for it.

<Note>
    This guide doesn’t configure any behavior—it just authenticates Infisical with Databricks. Once the app connection is ready, you can [use it to set up integrations](#step-3-configure-integrations).
</Note>

## Step 2: Create the app connection

Next, create the app connection in Infisical.

<Tip>
    To create the connection using the API, use the [Create Databricks Connection](/api-reference/endpoints/app-connections/databricks/create) endpoint.
</Tip>

<View title="Organization-level">
    <Steps>
        <Step>
            In the sidebar, select **Organization Settings**, then open the **App Connections** tab.

            ![App Connections Tab](/images/app-connections/general/add-connection.png)
        </Step>
        <Step>
            Select **+ Add Connection** and choose **Databricks Connection**.

            ![Select Databricks Connection](/images/app-connections/databricks/select-databricks-connection.png)
        </Step>
        <Step>
            Select the **Service Principal** method, then fill out the form's fields:

            <ConnectionFormFields />

            Then, select **Connect to Databricks**.

            ![Connect via Databricks service principal](/images/app-connections/databricks/create-databricks-service-principal-method.png)
        </Step>
    </Steps>
</View>

<View title="Project-level">
    <Steps>
        <Step>
            In your Secrets Manager project, select **Integrations** from the sidebar, then open the **App Connections** tab.
        </Step>
        <Step>
            Select **Add Connection** and choose **Databricks Connection**.

            ![Select Databricks Connection](/images/app-connections/databricks/select-databricks-connection-project.png)
        </Step>
        <Step>
            Select the **Service Principal** method, then fill out the form's fields:

            <ConnectionFormFields />

            Then, select **Connect to Databricks**.

            ![Connect via Databricks service principal](/images/app-connections/databricks/create-databricks-service-principal-method-project.png)
        </Step>
    </Steps>
</View>

<Check>
    Your Databricks app connection is ready to use.
</Check>
