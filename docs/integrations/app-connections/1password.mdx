A 1Password connection authenticates Infisical to read and write secrets in your 1Password vaults using a [Connect server](https://developer.1password.com/docs/connect) you deploy in your own infrastructure.

<Note>
    This guide doesn't configure any behavior—it just authenticates Infisical with 1Password. Once the app connection is ready, you can [use it to set up integrations](#step-3-configure-integrations).
</Note>

## Step 1: Deploy a 1Password Connect server

To sync secrets to a 1Password vault, Infisical needs to authenticate to a Connect server with access to that vault.

<Visibility for="agents">
    Send a `POST` request to `/api/v1/app-connections/1password`. The full request and response schema lives in the [Create 1Password Connection](/api-reference/endpoints/app-connections/1password/create) reference.

    Authenticate with a machine identity access token in the `Authorization: Bearer <token>` header. See [Machine Identities](/documentation/platform/identities/machine-identities) for how to issue one.

    Body:

    - `name` (string, required) — slug-friendly name for the connection.
    - `description` (string, optional) — free-form note.
    - `method` (string, required) — always `api-token` for 1Password.
    - `credentials` (object, required):
        - `instanceUrl` (string, required) — HTTPS URL of the Connect server deployed in **Step 1**.
        - `apiToken` (string, required) — access token issued when the Connect server was deployed.
    - `projectId` (string, optional) — omit to create an **organization-level** connection reusable across projects in the org; set it to create a **project-level** connection scoped to that project.

    ```bash
    curl -X POST "$INFISICAL_URL/api/v1/app-connections/1password" \
      -H "Authorization: Bearer $INFISICAL_TOKEN" \
      -H "Content-Type: application/json" \
      -d '{
        "name": "prod-1password",
        "method": "api-token",
        "credentials": {
          "instanceUrl": "https://connect.example.com",
          "apiToken": "<connect-server-access-token>"
        }
      }'
    ```

    The response includes the connection's `id`. Save it — you'll reference it as `connectionId` if you need to create a [1Password Secret Sync](/integrations/secret-syncs/1password).
</Visibility>

    Your 1Password app connection is ready to use.
