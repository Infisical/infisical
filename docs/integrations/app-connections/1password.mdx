A 1Password connection authenticates Infisical to read and write secrets in your 1Password vaults using a [Connect server](https://developer.1password.com/docs/connect) you deploy in your own infrastructure.

<Note>
    This guide doesn't configure any behavior—it just authenticates Infisical with 1Password. Once the app connection is ready, you can [use it to set up integrations](#step-3-configure-integrations).
</Note>

## Step 1: Deploy a 1Password Connect server

To sync secrets to a 1Password vault, Infisical needs to authenticate to a Connect server with access to that vault.

<DeployConnectServer />

## Step 2: Create the app connection

Next, create the app connection in Infisical.

<Tip>
    To create the connection using the API, use the [Create 1Password Connection](/api-reference/endpoints/app-connections/1password/create) endpoint.
</Tip>

<View title="Organization-level">
    <Steps>
        <Step>
            In the sidebar, select **Organization Settings**, then open the **App Connections** tab.

            ![App Connections Tab](/images/app-connections/general/add-connection.png)
        </Step>
        <Step>
            Select **+ Add Connection** and choose **1Password Connection**.

            ![Select 1Password Connection](/images/app-connections/1password/app-connection-option.png)
        </Step>
        <Step>
            Fill out the form's fields:

            <ConnectionFormFields />

            Then, select **Connect to 1Password**.

            ![1Password Connection Modal](/images/app-connections/1password/app-connection-modal.png)
        </Step>
    </Steps>
</View>

<View title="Project-level">
    <Steps>
        <Step>
            In your Secrets Manager project, select **Integrations** from the sidebar, then open the **App Connections** tab.
        </Step>
        <Step>
            Select **Add Connection** and choose **1Password Connection**.

            ![Select 1Password Connection](/images/app-connections/1password/app-connection-option-project.png)
        </Step>
        <Step>
            Fill out the form's fields:

            <ConnectionFormFields />

            Then, select **Connect to 1Password**.

            ![1Password Connection Modal](/images/app-connections/1password/app-connection-modal-project.png)
        </Step>
    </Steps>
</View>

<Check>
    Your 1Password app connection is ready to use.
</Check>
