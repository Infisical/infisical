---
title: "Portainer sync"
description: "Learn how to configure a Portainer Sync for Infisical."
---

**Prerequisites:**

        - Set up and add secrets to [Infisical Cloud](https://app.infisical.com)
        - Create a [Portainer Connection](/integrations/app-connections/portainer)

Infisical syncs secrets to the environment variables of a Portainer stack.

<Note>
    **How the stack is updated depends on its type.**

    **Git-backed stacks:** Infisical writes the variables to the stack's Git settings. The running
    containers are left untouched, and the new values take effect on the stack's next deployment
    (an auto-update poll, a webhook, or a manual redeploy).

    **File-based stacks:** Portainer requires the compose file on every update, so Infisical
    resubmits the current file unchanged along with the variables, and Portainer redeploys the
    stack. Infisical skips the update if the stack already has exactly these variables. Otherwise
    Infisical waits for the redeploy to finish, and if Portainer reports that the redeploy failed,
    the sync fails with Portainer's error message.

    **Kubernetes stacks:** Portainer doesn't apply environment variables to Kubernetes stacks, so
    Infisical doesn't list them as a destination and fails a sync that targets one.

    If you need variables to land without restarting anything, use a Git-backed stack.
</Note>

<Note>
    Portainer stores a Compose stack's variables in an env file with one line per variable. If a
    value contains line breaks, such as a PEM certificate, Infisical stores the value in double quotes
    with each line break escaped as `\n`, and Portainer restores the line breaks when it deploys the
    stack. Swarm stacks receive multiline values as-is.
</Note>

<Tabs>
    <Tab title="Infisical UI">
        1. Navigate to **Project** > **Integrations** and select the **Secret Syncs** tab. Select **Add Sync**, then select **Portainer** as the destination.
        ![Choose Portainer Destination](/images/secret-syncs/portainer/step-1.png)

        2. Configure the **Source** to specify where secrets should be retrieved from, then select **Continue**.
        ![Configure Source](/images/secret-syncs/portainer/step-2.png)

            - **Environment**: The project environment to retrieve secrets from.
            - **Secret Path**: The folder path to retrieve secrets from.
            - **Include secrets from all subfolders**: If enabled, secrets in every folder beneath the path are synced too.

        <Tip>
            If you need to sync secrets from multiple folder locations, check out [secret imports](/documentation/platform/secret-reference#secret-imports).
        </Tip>

        3. Configure the **Destination** to specify where secrets should be deployed, then select **Continue**.
        ![Configure Destination](/images/secret-syncs/portainer/step-3.png)

            - **Portainer Connection**: The Portainer Connection to authenticate with.
            - **Environment**: The Portainer environment (endpoint) that hosts the stack.
            - **Stack**: The stack whose environment variables should be updated.

        4. Configure the **Initial Sync Behavior** to determine how Infisical should resolve the first sync, then select **Continue**.
        ![Configure Initial Sync](/images/secret-syncs/portainer/step-4.png)

            - **Overwrite Portainer**: Infisical writes its secrets to the stack. No variables are imported back.
            - **Import from Portainer, prioritize Infisical**: Existing stack variables are imported into Infisical first; where a key exists on both sides, the Infisical value wins.
            - **Import from Portainer, prioritize Portainer**: Same as above, but the stack's value wins on conflicts.

        5. Configure the **Sync Options** to control how secrets are written, then select **Continue**.
        ![Configure Sync Options](/images/secret-syncs/portainer/step-5.png)

            - **Prevent secret deletion**: If enabled, Infisical never removes variables from the stack during a sync. Enable this if you manage some variables manually outside of Infisical.
            - **Auto-sync on changes**: If enabled, secrets are synced automatically whenever they change in the source. Turn off to sync manually only.
            - **Customize key names**: Add a prefix or suffix so Infisical can identify which variables in the stack it manages. Anything else is left untouched.

        <Warning>
            A Portainer stack stores its variables as a single list, so a sync rewrites that whole list.
            Without a key schema, every existing variable on the stack is treated as managed by this sync
            and may be removed once it leaves the source. Use **Customize key names** or **Prevent secret
            deletion** to preserve variables set outside of Infisical.
        </Warning>

        6. Configure the **Details** of your Portainer Sync, then select **Continue**.
        ![Configure Details](/images/secret-syncs/portainer/step-6.png)

            - **Name**: The name of your sync. Must be slug-friendly.
            - **Description**: An optional description for your sync.

        7. Review your Portainer Sync configuration, then select **Create Sync**.
        ![Review Configuration](/images/secret-syncs/portainer/step-7.png)

        8. Your Portainer Sync is created and will begin syncing your secrets to the destination.
        ![Sync Created](/images/secret-syncs/portainer/step-8.png)

    </Tab>
    <Tab title="API">
        To create a **Portainer Sync**, make an API request to the [Create Portainer Sync](/api-reference/endpoints/secret-syncs/portainer/create) API endpoint.

        ### Sample request

        ```bash Request
        curl    --request POST \
        --url https://app.infisical.com/api/v1/secret-syncs/portainer \
        --header 'Content-Type: application/json' \
        --data '{
            "name": "my-portainer-sync",
            "projectId": "3c90c3cc-0d44-4b50-8888-8dd25736052a",
            "description": "an example sync",
            "connectionId": "3c90c3cc-0d44-4b50-8888-8dd25736052a",
            "environment": "prod",
            "secretPath": "/my-secrets",
            "isEnabled": true,
            "syncOptions": {
                "initialSyncBehavior": "overwrite-destination"
            },
            "destinationConfig": {
                "environmentId": 1,
                "stackId": 4
            }
        }'
        ```
