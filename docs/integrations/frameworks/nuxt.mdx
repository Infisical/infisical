Prerequisites:

- Set up and add envars to [Infisical Cloud](https://app.infisical.com)
- [Install the CLI](/cli/install)

## Initialize Infisical for your [Nuxt](https://nuxtjs.org) app

```bash
# navigate to the root of your of your project 
cd /path/to/project

# then initialize infisical
infisical init
```

## Start your application as usual but with Infisical

```bash
infisical sm run -- <your application start command>

# Example
infisical sm run -- npm run dev
```
