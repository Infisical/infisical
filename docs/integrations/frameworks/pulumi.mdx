[Pulumi](https://www.pulumi.com/) can use the [Infisical Terraform provider](https://registry.terraform.io/providers/Infisical/infisical/latest/docs) through Pulumi's Any Terraform Provider feature. This lets you manage Infisical projects and secrets from Pulumi programs written in TypeScript, Python, Go, C#, or Java.

## Prerequisites

- [Pulumi CLI](https://www.pulumi.com/docs/install/) installed
- An Infisical project
- A [machine identity](https://infisical.com/docs/documentation/platform/identities/machine-identities) with access to the project

## Add the provider

Create a Pulumi project, then add the Infisical Terraform provider. Pulumi generates a typed SDK for your project.

```bash
pulumi new typescript
pulumi package add terraform-provider Infisical/infisical
```

Pin the provider version when you need reproducible builds:

```bash
pulumi package add terraform-provider Infisical/infisical <provider-version>
```

Run `pulumi install` after cloning a project to install the provider and any generated SDK files recorded in `Pulumi.yaml`.

## Authenticate the provider

Set the provider authentication variables before running Pulumi. The token must belong to a machine identity with permission to the project.

```bash
export INFISICAL_AUTH_METHOD=token
export INFISICAL_TOKEN=<machine-identity-token>
export INFISICAL_HOST=https://app.infisical.com
```

`INFISICAL_HOST` is optional when you use Infisical Cloud. Set it to your self-hosted Infisical URL when needed.

## Manage a secret with TypeScript

Set the secret value as encrypted Pulumi configuration, then create or update the secret through the generated SDK.

```bash
pulumi config set apiKey <secret-value> --secret
```

```typescript
import * as pulumi from "@pulumi/pulumi";
import * as infisical from "@pulumi/infisical";

const config = new pulumi.Config();

const secret = new infisical.Secret("api-key", {
  name: "API_KEY",
  value: pulumi.secret(config.require("apiKey")),
  envSlug: "dev",
  workspaceId: "<project-id>",
  folderPath: "/",
});

export const secretId = secret.id;
```

## Manage a secret with Python

The generated Python SDK uses snake case for resource properties.

```python
import pulumi
import pulumi_infisical as infisical

config = pulumi.Config()

secret = infisical.Secret(
    "api-key",
    name="API_KEY",
    value=pulumi.secret(config.require("apiKey")),
    env_slug="dev",
    workspace_id="<project-id>",
    folder_path="/",
)

pulumi.export("secret_id", secret.id)
```

For Pulumi HCL projects, declare `Infisical/infisical` in a `required_providers` block and run `pulumi install`. Use the Terraform provider's resource names and fields in your `.tf` files. See the [Infisical Terraform provider documentation](https://registry.terraform.io/providers/Infisical/infisical/latest/docs) for the available resources and data sources.
