---
title: "Login"
openapi: "POST /api/v1/auth/tls-cert-auth/login"
---

<Warning>
  On Infisical Cloud and dedicated instances, send this request to port `8443`, not `443`. Use the address for your instance:

  - US: `https://app.infisical.com:8443`
  - EU: `https://mtls.eu.infisical.com:8443`
  - Dedicated instance: your instance's address on port `8443`
</Warning>
