---
title: "Delete project"
openapi: "DELETE /api/v1/projects/{projectId}"
---

<Warning>
    By default, a Secrets Management project stays restorable for 14 days before Infisical permanently deletes it. Set `hardDelete` to `true` to skip the grace period. Infisical permanently deletes other project types right away. Permanently deleted projects can't be recovered.
</Warning>
