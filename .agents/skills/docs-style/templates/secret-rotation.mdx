## Step 2: Set up the rotation in Infisical

<Tip>
    To create the rotation using the API, use the [Create {Rotation name} Rotation](/api-reference/endpoints/secret-rotations/{rotation-slug}/create) endpoint.
</Tip>

<Steps>
    <Step>
        In your Secrets Manager project, open the dashboard and select **Add Secret Rotation** from the actions dropdown.

        ![Add Secret Rotation](/images/secret-rotations-v2/generic/add-secret-rotation.png)

        Then, select the **{Rotation option label}** option.
    </Step>
    <Step>
        Under **Configuration**, choose the app connection and when the rotation runs:

        {/* IF: the form shows an Environment field */}
        - **Environment**: The project environment the rotated secrets are stored in
        {/* END IF */}
        - **{Product} Connection**: The app connection the rotation uses
        - **Rotation Interval (In Days)**: The number of days between rotations
        - **Rotate At (Local Time)**: The time of day the rotation runs
        - **Auto-Rotation Enabled**: When enabled, the credential rotates on the schedule; turn it off to rotate manually only

        <Tabs>
            <Tab title="Create a new app connection">
                Under **{Product} Connection**, select **Create Connection** in the dropdown, then fill in:

                <ConnectionFormFields />

                Select **Connect to {Product}**. Infisical returns you to the rotation form with the new connection selected.

                <Note>
                    This creates a connection scoped to the current project. To share the connection across other projects, [create it at the organization level](/integrations/app-connections/{product-slug}#step-2-create-the-app-connection) first, then select it here.
                </Note>
            </Tab>
            <Tab title="Use an existing connection">
                Under **{Product} Connection**, select the app connection you'd like to use.
            </Tab>
        </Tabs>

        ![Rotation Configuration](/images/secret-rotations-v2/{rotation-slug}/{image-file}.png)

        Then select **Continue**.
    </Step>
    <Step>
        Under **Parameters**, choose {the {Product} resource whose credential Infisical rotates}:

        {/* NOTE: One bullet per field in SecretRotationV2ParametersFields/ for this rotation. */}
        - **{Field label}**: {What the field selects in {Product}}

        ![Rotation Parameters](/images/secret-rotations-v2/{rotation-slug}/{image-file}.png)

        Then select **Continue**.
    </Step>
    <Step>
        Under **Mappings**, choose the names of the Infisical secrets that hold the rotated values:

        {/* NOTE: One bullet per field in SecretRotationV2SecretsMappingFields/ for this rotation. */}
        - **{Field label}**: The name of the secret that holds {the rotated value}

        ![Secret Mapping](/images/secret-rotations-v2/{rotation-slug}/{image-file}.png)

        Then select **Continue**.
    </Step>
    <Step>
        Give the rotation a **Name** and an optional **Description**. The name must be slug-friendly.

        ![Rotation Details](/images/secret-rotations-v2/{rotation-slug}/{image-file}.png)

        Then select **Continue**.
    </Step>
    <Step>
        Review your {Rotation name} Rotation configuration, then select **Create secret rotation**.

        ![Review and Create](/images/secret-rotations-v2/{rotation-slug}/{image-file}.png)

        <Check>
            The rotated credentials are now available through the mapped secrets. If auto-rotation is enabled, they rotate on your configured schedule.
        </Check>
    </Step>
</Steps>
