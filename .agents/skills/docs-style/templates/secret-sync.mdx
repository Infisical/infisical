        <Warning>
            {What the secrets in {Product} belong to}, so a sync can change secrets that were created outside Infisical. If you don't customize key names, the sync treats every secret in {the destination} as one it manages:

            - If a {Product} secret has the same name as an Infisical secret, the sync overwrites the {Product} secret's value
            - If **Prevent secret deletion** is off, every {Product} secret that isn't in Infisical is deleted

            With customized key names, the sync writes only names with your prefix or suffix, and deletes only {Product} secrets whose names match it.

            Before the first sync, customize key names or keep **Prevent secret deletion** on. **Prevent secret deletion** is on by default when you create the sync in the UI, but off unless you set `disableSecretDeletion` when you create it through the API.
        </Warning>
